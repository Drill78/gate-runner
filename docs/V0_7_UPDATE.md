# 灰烬之门 v0.7

本版优化现有十五关远征。真实3D主角、怪物模型与骨骼动画属于下一版；本版改进配乐、场景、排版、战斗机制与成长。

## 战斗与难度

- 修复上方已可见目标尚未进入旧激活线时，弹体穿过却不扣血的问题。普通攻击、技能、灼烧与范围伤害使用可见范围；首领特写暂停期间仍禁止攻击。
- 首次普通通关后解锁困难模式；已有通关收藏也会直接解锁。困难敌人生命+10%，攻击伤害+8%。第5关同时迎战守望者与古龙，第10关同时迎战巫妖与先知。
- 双首领左右站位、独立生命条与战斗状态。每位拥有对应普通首领66%的生命，合计132%；伤害另乘0.78，开场错开2.2秒。必须击败双方才完成房间并领取一次奖励。
- 双首领共享压力计时，宽限比普通多6秒；击败一位不会重置计时。最终王仍为单首领。
- 普通关底基础生命1290→1580，精英1650→2250，禁域精英3300→4100；三幕关底系数为1/1.15/1.5，前两幕章节系数提高为1.6/2.2。第三幕精英第一轮即使用招牌招式。
- 普通最终王生命仍约297321。70%和35%换阶段时产生错时两侧火墙，并新增「王座断界」的连续封路与中央重击；保留火环、陨火、交叉焚风和可打断的敕令。

## 成长、轮抽与收藏

- 武器上限10→25级；前十级每级+10%基础攻击，第11–25级每级+5.5%，避免后期失控。游侠基础攻击5.4→5.9。
- 角色每级生命上限与当前生命+6。新遗物「不灭心脏」提高当前生命上限12%并恢复等量生命；「余烬生息」每完成一关增加3/层最大生命并恢复等量。总生命上限1200，遗物共35项。
- 「聚能刻印」每层弹体半径+65%，同步扩大画面和物理碰撞。
- 「炼金火芯」对命中目标额外造成20%/层弹体伤害，对附近目标造成65%/层，扩大范围。
- 「秘火余烬」每秒造成当前基础齐射伤害32%/层，持续3秒；「荆棘冠冕」反击80%/层基础齐射伤害。骑士技能护盾为18+最大生命10%，再加圣约加成。
- 问号事件改成固定种子的两份契约与一份旅费选项。可遇到血誓遗藏、军团招募、流浪铸剑师、生命之井、烙印宝库、无名贤者、旅人回礼。效果随幕、关数或人物属性成长。
- 血誓遗藏按最大生命支付代价，进入真正三选一珍藏轮抽，必含史诗或传说。不可重复结算房间、选择未提供项目或支付不足的代价。
- 成就18→29项：困难通关、双王与四王、无伤章节战、单局累计1500/2200金币、15/25级武器、240最大生命、15宝箱和15种遗物。累计金币不会因消费减少。

## 禁域与美术

禁忌秘钥价格666金币，持有未使用钥匙时路线图变暗。强化节点与路线卡边框燃烧黑色火焰，去掉旋转方框。五道必经红门去掉标题文字，只保留门和数值；削减改为14%、÷1.22、17%、÷1.25、20%，仍保持最终窄平方门的路线机制。

三幕分别使用AI生成的苔石荆棘道路、蓝紫月蚀回廊、黑曜余烬王庭，替代程序化格子背景。新增四张WebP合计约1.20MB；材质集中在边缘，中间保持可读。新增Noto Serif SC的本地子集字体，采用OFL1.1，授权文件随站点提供，标题与数字使用更克制的金石排版。

前三首配乐统一112 BPM并共享D小调主题。普通战以旋律和吉他推进；Boss战加入铜管主奏、弦乐回答与定音鼓；最终战以弦乐断奏、低弦、铜管、无字合唱和重吉他构成交响金属。均为原创程序化器乐合成。《门后的低语》保持v0.6文件逐字节不变。详细测量见[配乐](MUSIC.md)。
