# 灰烬之门 1.0 正式版

2026-09-08。结束 Early Access。本次集中更新配乐和困难双首领血条，玩法数值、敌人招式、难度曲线、成就、奖励与存档格式沿用 v0.7。

## 配乐

- 普通战《破晓行军》：116 BPM，上扬主题、弦乐回答、拨弦桥段和高音域重奏。
- 首领战《暴君的审判》：82 BPM，降 D 低音、半音下行铜管、断拍重击与低弦；独立旋律，只在第 14–15 小节（从零计数）短暂引用普通主题。
- 最终战《圣烬加冕》：96 BPM，10 秒管风琴、合唱与钟声前奏，随后进入 D 大调圣咏与交响金属。30 秒起进入主题回忆，40 秒起回到原小调主题，再推向大调加冕。首次从零播放，循环从第 10 秒开始，前奏不反复打断战斗。
- 主界面《誓言尚未熄灭》：安静号角、弦乐和钟声。
- 地图《灰林远行》：竖琴式分解和弦、木管和稀疏弦乐；战后选奖和营火也采用此曲。
- 问号事件《命运的岔路》：错落钟琴与悬置和声。
- 商店《炉火与铜币》：摇摆鲁特琴、拨奏低音与木管。
- 禁忌之门《门后的低语》：原文件完整保留。

新增曲目仍为原创程序合成器乐，没有外部音乐片段或第三方录音采样。采用统一响度与分场景播放音量，场景曲音量稍低。音乐在首次点击或按键后开始，按需加载，最多缓存三首解码音频；切曲增加淡入淡出，后台和静音暂停。音乐导出数据、母带说明与制作入口见 [MUSIC.md](MUSIC.md)。

## 界面与正式版标识

困难双首领的两条血条改为左右并排，依次显示名称、精确生命、状态。名字过长时省略，完整名称仍在标题属性和无障碍生命读数中保留。低矮屏幕合并顶部人物与资源信息行，并上移双血条，减少覆盖首领。单首领血条沿用原布局。

主入口、页脚、浏览器标题及包版本统一为 1.0 正式版；不再显示 Early Access。旧远征和收藏继续沿用原存储键与格式。

## 发布范围

按用户要求，不重跑玩法测试、难度模拟或浏览器测试。本轮只做 TypeScript、lint、生产构建、音频导出质量检查与发布后的静态资源核验。v0.7 的 134 项测试和 204 局模拟属于历史证据，不计作 1.0 新测试。

发布入口与部署记录见 [DEPLOYMENT.md](DEPLOYMENT.md)。本次没有制作真实 3D 角色或怪物模型。
