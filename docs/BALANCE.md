# 灰烬之门 · 数值与难度 v0.2

更新：2026-09-07。这里记录当前实现，不把后续规划混入数值表。程序中的楼层从 0 开始，本文从 1 开始。

## 核心目标

第一幕建立持续瞄准与过门习惯；第二幕开始要求输出、续航和走位协同；第三幕以短反应窗口和高生命首领检验构筑。兵力单独增长无法抵消敌人成长。装备、遗物和职业共鸣必须参与输出。

## 兵力、攻击与齐射

- 兵力 N 是军团规模，不是生命值，也不是 N 个独立子弹发射器。
- 兵力加成 M = 1 + log₂(1 + N / 12)。没有 999 上限；程序只在 JavaScript 安全整数上限 9,007,199,254,740,991 保护运算。
- 攻击强度 D = 职业基础 × [1 + 0.1 × (武器等级 − 1)] × [1 + 0.2 × 钢刃层数 + 0.25 × 奔涌层数] × [1 + 当前护盾 × 盾锋层数 × 0.005] × 骑士共鸣倍率。
- 一次齐射伤害 = D × M；每秒火力 = 齐射 × 攻速 × [1 + 暴击率 × (暴击倍率 − 1)]。
- 面板显示常态直击期望，不计骑士技能的 1.5 倍临时增伤、灼烧、回响、弹射和反击。瞄准时间不足也会降低实际 DPS。
- 伤害受到目标护甲减免，技能与附加伤害也经过该减免。

## 职业主动技与共鸣

- **誓约骑士 · 不破誓约**：获得 18 护盾，6 秒内伤害提高 50%。
- **灰林游侠 · 箭雨齐射**：对所有可见敌人和宝箱造成 4 倍单次伤害。
- **秘火法师 · 秘火新星**：对所有可见目标造成 4.5 倍单次伤害，召唤 3 名队员。

基础冷却 12 秒，对应职业史诗遗物缩短至 8 秒。骑士不灭圣约额外 +12 技能护盾，因此总计 30；护盾上限 250，关卡结束后不继承，下一关按初始护盾重置。

职业遗物累计 3 层激活共鸣，同一遗物 3 层也可：骑士伤害 ×1.15，游侠暴击 +10 个百分点，法师攻速 +20%。通用遗物不计入。

## 移动、命中与预警

- 世界横坐标在 −0.9 至 +0.9 之间连续移动，速度每秒 1.45 单位，完整横穿约 1.24 秒。鼠标/触屏指定位置也受相同速度限制。
- 所有实体采用线性纵向运动，距离不改变体积。每幕速度固定，换幕才加快。首领到达场地中央附近后停留。
- 自动射击：横向差距小于 0.24 + 目标半宽，优先最先越界的可见目标。一般单位宽 0.23，首领宽 0.45。
- 弓手出现约 0.9 秒开始瞄准，1.05 秒预警后在锁定位置落箭；后续间隔 3.6 秒。修复了旧版射击晚于越界的缺陷。
- 首领攻击间隔 2.65 秒。荆棘守望者锁定当前位置，宽 0.48，预警 1.1 秒；蚀月巫妖在三片区域随机保留一片安全区，另两片宽 0.60，预警 1 秒；灰烬之王同时锁定玩家与另一侧区域，预警 0.85 秒。
- 幕首领基础伤害 17 + (楼层−1)×1.6；普通/精英关底 12 + (楼层−1)×1.4。出现 22 秒后狂暴，伤害 ×1.75，没有瞬杀倒计时。
- 预警落下时以队长中心判断，半宽额外容差 0.035。队伍展示的士兵不增加碰撞宽度。

## 受伤和资源流失

先按护甲减伤并向上取整，再消耗护盾，剩余扣生命。护盾完整吸收则不损兵。实际生命受伤时：预警损兵 10%，撞到漏怪 14%，绕开但未击杀的漏怪 7%，荆棘 13%，每次向上取整，至少留 1 人。漏怪也伤害玩家，不能通过躲到边缘无代价跳过全部战斗。

漏怪伤害：撞到 14 + (楼层−1)×1.25，绕开 8 + (楼层−1)×1.25；荆棘 18 + (楼层−1)×1.8。生命归零立即失败，不再继续推进。
