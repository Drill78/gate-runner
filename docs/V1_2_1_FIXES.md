# 1.2.1 · 真人反馈修复

本版按实际试玩反馈修正登神远征，延续原来的战斗模型风格，不涉及独立的3D重构工程。

## 首领与演出

- 焚誓重生、登神王、主神的场内形象全部改为可随施法动作变化的Canvas程序模型；立绘保留在突入和图鉴中。主神六翼六臂横跨战场，登神王的白金日冕与黑曜蚀日有明确形态差异。
- 按既定阵容，第97关为命运先知，第98关为天使化灰烬之王。修复第98关天使复生吞掉王的真正二阶段：第一管生命耗尽后进入十秒圣翼狂怒，碎翼后以四秒突入衔接焚誓重生，不再重复一管旧招式。
- 第99关第二阶段改为蚀日形态，拥有六招独立技能、三处移位与更紧凑的出招节奏。形态切换拥有完整四秒突入。
- 主神从六招扩展到十一招，新增万象之弦、天平圣约、逐星织路、寂静钟鸣和破雾终曲；保留宽阔生路与完整演出窗口。
- 双首领分别播放完整突入；连战每组重新播放，三王分别播放四秒。同一时刻多个首领复生会排队展示，不再覆盖前一位的动画。
- 去掉没有碰撞意义的施法、冲击和足底装饰圆圈；保留与伤害范围相符的预警、绿区和无敌护盾轮廓。

## 长阶与奖励

天使护佑提升至80%减伤，91—98生命预算约提高35%、攻击约提高12%；99生命预算提高至原来的六倍，并加强机制压力。100关保持较宽松的收束战定位。

91关预设基础输出保持160万DPS，生命调整为骑士400、游侠560、法师540。真实正常路线的良好构筑明显高于预设。程序横移与技能样本中，三职业均可通过新长阶；独立99关的三职业活动样本通过、站桩对照全部失败。这些是确定性引擎样本，不是真人胜率。

66,666金币秘钥保留：真实游侠路线在87关以68,639金币购买，扣款后1,973。保留666／6,666／66,666三级，删除更高档位，避免继续获得无用残章。路线与储蓄时机仍决定第三把能否买到。完整证据见[数值复核](V1_2_FEEDBACK_BALANCE_AUDIT.md)。

同时修复契约池耗尽后重复奖励导致的存档恢复失败；兼容此前写出的这一特定重复奖励，保留资源、身份与进度。

## 界面与文本

- 结算页恢复自身滚动容器；小屏幕可向下滚动完整战绩，百关结算顶部与底部均可进入祝福尾声。
- 指定首领演练直接进入交锋；完整路线仍保留正常关卡。直接首领战不再显示无效的“1/0波”，关闭设置时不再短暂闪现教程。
- 开发者演练的返回入口固定在屏幕底部，结算另有返回演武场和退出演练；返回保留已解锁控制台，退出恢复进入前的正式远征。
- 结束状态隐藏战斗HUD，避免覆盖统计；首次开发者演练不再自动弹出正式教程。
- 普通游戏的突入、血条、地图引言和教程不再提前报出命数与结尾流程；当前状态和实际危险提示仍清晰显示。开发者测试说明保留准确的机制信息。
- 首页、页面标题、版本标识与中文字体同步更新。

## 人工复核入口

设置 → 开发者演武场 → 口令 `721604`。默认生命和火力倍率均为1；难度试玩请保持默认。

1. 「第六轮·终夜守门人」：检查两组双首领与最后三王分别突入。
2. 「登神长阶·完整流程」：从91关体验至结尾，重点观察98关碎翼衔接及99关蚀日形态。
3. 「万光之源」：观察十一招及完整通关流程。
4. 「百关结算 → 祝福尾声」：检查窄屏滚动、顶部入口、101关祝福与最终署名。
5. 每次结束点击「返回演武场」切换测试；「退出演练」恢复正式远征。演练不写入正式排行榜和成就。

自动测试、浏览器交互及线上检查的最终结果归档于[发布交接](RELEASE_HANDOFF.md)。浏览器中的高生命／高火力仅用于快速检查界面，不计入难度验证。
