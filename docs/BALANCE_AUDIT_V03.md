# 难度审计 · v0.3

2026-09-07，独立审计智能体对冻结战斗参数运行每职业、每策略 32 个种子；移动与站定各 288 次，共 576 次远征尝试。之后仅调整消息显示和视野投影，战斗参数没有变化。旧报告保留在 [v0.2 历史审计](BALANCE_AUDIT_V02.md)。

## 正常移动结果

| 选卡策略      | 骑士  | 游侠  | 法师  |
| ------------- | ----- | ----- | ----- |
| 合理职业构筑  | 32/32 | 29/32 | 32/32 |
| 经济/兵力优先 | 25/32 | 2/32  | 11/32 |
| 不选遗物      | 0/32  | 0/32  | 0/32  |

这是数学预判弹道的控制器基准，**不是人类玩家胜率，也不是所有构筑必过的保证**。三个职业不选遗物均失败；合理构筑游侠的三次失败都来自末幕漏怪，没有发现全屏伤害无解。好构筑每战平均净生命损失为骑士 0.04、游侠 7.33、法师 1.41；同帧治疗/升级会抵消损失，因此该指标不是总承伤量。

骑士更宽容。经济优先组仍可能随机获得很强的盾锋、吸血和圣约组合，因此其 78.1% 不能解释成任意差构筑都能过。例如种子 1743 最终有盾锋 2、血饮 3、不灭圣约 1、橡木之心 1、号角 1，本身已形成续航组合。先保留本轮数值，实际试玩再观察骑士的宽容度。

## 站定对照

完全不横移，但继续选卡、释放技能和定时格挡：骑士合理构筑 20/32，其余职业/策略均 0/32。此组仍主动操作，不能称为挂机通关。它说明护盾、格挡、反击与治疗能形成主动承伤打法，符合不把所有首领都做成躲红框的设计方向。

## 首领与经验检查

最初候选版首领首次动作延后到 5.9 秒，一些成型构筑会在首次动作前击杀首领。最终版首次动作约登场 0.9 秒，合理构筑所有成功击败的首领均已出招。

| 成功首领遭遇的平均时长（不含前置波次） | 骑士    | 游侠     | 法师    |
| -------------------------------------- | ------- | -------- | ------- |
| 第一幕                                 | 8.28 秒 | 8.81 秒  | 5.54 秒 |
| 第二幕                                 | 6.04 秒 | 7.79 秒  | 6.15 秒 |
| 第三幕                                 | 8.54 秒 | 12.38 秒 | 9.82 秒 |

第三幕游侠此处只算 29 个成功样本，CSV 的 avgBossTime 是另一项跨幕指标，不能混用。好构筑共触发 126 次王的仪式，其中 94 次格挡结算、21 次打断、11 次随击杀取消。王首先震荡，再交叉弹幕，再可打断吟唱，使不同应对方式有实际展示机会。

独立机制检查通过：同批双弹只伤害一次；三个职业格挡保护兵力且有独立冷却；打断取消仪式；已死亡首领不再结算仪式；首次攻击约 0.9 秒；正面盾伤害为侧翼的 30%。经验从正常清怪获得，通关多为 Lv10，提供约 18% 攻击和 18 点生命上限；升级不回满血。

## 控制器与复现

种子为 734 + i×1009，i 为 0 至 31。所有远征正常开局、零遗物、Lv1 武器，通过实际地图和三选一逐步构筑。每步 50ms，每 150ms 决策，使用真实移动速度并考虑格挡减速。只读取已出现实体、已公布预警和已发射弹幕，不偷看未发射弹幕或未来随机奖励。根据已展示轨迹预测落点，优先瞄准最早到期目标、选择可达好门，举盾时转向侧翼，吟唱时集火并在临近结算时格挡。

路线优先营火 → 宝库 → 普通战斗 → 商店 → 首个合法节点。营火生命低于 75% 则治疗，否则锻造；商店缺血超过 20 时买药，之后买遗物和武器。不选遗物组跳过奖励和商店遗物，仍保留技能、经验、武器、门与治疗。这是偏稳健、重视宝箱的路线，不能当作精英连战的基准。

合理选卡优先级：

- 骑士：bash → paladin → aegis → bulwark → steel → plate → vampire → vitality → mirror → army → thorns → recruit → bounty。
- 游侠：hunter → quiver → keen → deadeye → steel → vampire → vitality → ricochet → mirror → army → ambush → recruit → bounty。
- 法师：archmage → surge → echo → ward → steel → vampire → vitality → ember → mirror → army → summon → recruit → bounty。

候选基础评分 100−5×序号；低于 60% 生命时橡木之心 +60，9 层以前第一层血饮 +30，第一层盾锋 +35，有盾锋时第一层誓言回响 +30。经济优先组优先通用遗物，其内顺序为钱币、号角、双生、战旗；其他通用牌照常接受。所有模式只使用实际提供的合法候选。

运行 `npm run test:balance -- 32`，生成被 Git 忽略的 `artifacts/balance-results.json`。设置 `STATIONARY=1` 得到站定对照；另支持 `CLASS_FILTER`、`MODE_FILTER`、`PILOT_REACTION`、`DEFENSE=0`、`RESULT_FILE` 和 `ENGINE_ROOT`。移动与站定摘要保存在 [CSV](balance-summary.csv)。模拟器仅供开发验证，不接入产品自动游玩。

## 验证边界

机制测试、类型检查、静态检查和生产构建用于本次验收。没有进行浏览器点击、截图或真机触屏测试；自动控制器不能评估手指遮挡、读条辨认、不同帧率与真人反应时间。32 个种子也未穷尽所有路线和六套构筑。下一轮试玩优先记录死亡层、漏怪、经验等级、武器等级以及弹幕/仪式受伤来源。
