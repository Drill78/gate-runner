## 方法和核验

- 从零遗物、武器 Lv1 的真实 createRun 起步，种子 734/1743。逐次沿 availableNodes 的显式连接选路，通过实际升级、奖励、商店和房间 API 成长，不预装毕业构筑。
- 控制器每 .15 秒读一次公开状态，以 .05 秒步长调用引擎；仅对已出现实体与可见预警做弹道预测。移动调用 movePlayer，使用实际指针限速 12；正常释放职业技能。
- 构筑按脚本 priorities 的职业协同顺序选卡，低生命提高生命/吸血优先级，补给按当前实际收益评分。低生命优先可达营火；每幕在生命足够时尝试精英，其余路线与商店策略固定，不读取未来奖励。
- 49 次升级均来自实际候选，各房 talentPicks 与累计选择次数一致，存活房次数等于 level−1。29 份精英/章节奖励均有三项不重复候选和史诗/传说；4 次补给均为实际提供选项。
- 11 次商店购买均来自对应库存，无同店重复，购买由 canBuyShopItem/shopBuy 校验和扣费。保存数据未包含逐笔金币流水，不把库存核验表述为独立账务重放。
- 每个已完成节点都只推进一关；本批没有触发强化精英或特殊门，不追加种子搜寻。一次性资格、真实地图精英替换和满池保底由专项测试覆盖。

新版地图/奖励专项共 16 项测试通过，其中精英候选检测覆盖三个职业共 600 组种子、普通与强化精英、补给替换、仅剩传说、全部池满层及实际备用品效果。最终首领机制测试由主任务单独执行。

## 复现

在项目根目录、Node.js 24 下执行：

```powershell
$env:MODE_FILTER = 'coherent'
$env:RESULT_FILE = 'artifacts/balance-v06-final-smoke.json'
node scripts/balance-sim.mjs 2
```

控制器比真实触屏玩家更稳定地预测弹道、准确进入窄门；常规弹幕在这组样本中零命中，不能当成人类可轻松做到的基准。本轮没有扩测经济、无遗物或站定组，也没有据这 6 局调参。历史数值调校和最终王强化前的中间烟测不属于发布结果。
