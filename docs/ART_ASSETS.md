# 美术资产 v0.5

v0.5 复用五种首领的独立竖版立绘、三位职业立绘和城堡背景，没有新增位图依赖。新增表现来自代码：原创强敌突入、大血条、玩家向前弹幕与命中反馈、右侧技能按钮和首次访问图文教程。战斗继续使用等比例俯视 Canvas，兵力数字以大号描边文字显示在队伍上方，跟随队长横移。旋转斧刃、摇摆星弹、交叉火弹、正面举盾、吟唱收缩环和章节压力扩散环沿用 Canvas 绘制。

本版为原创中世纪奇幻气质。立绘具有精致 3D 渲染质感，但交付文件仍为 2D 图像，没有可编辑 3D 网格、骨骼或角色动画。

## 人物与首领风格

职业统一要求：原创、完整身体、成年人物、透明背景、3D 微缩模型渲染质感、暖主光与冷轮廓光、细致但克制的金属/皮革/布料、无文字和 UI。骑士为钢甲、黄铜边、象牙战袍、绛红披风、长剑与盾；游侠为精灵女性、深绿兜帽、实用皮甲、弓与箭袋；法师为成熟人类男性、梅紫长袍、法杖与少量蓝金余烬。

五种首领保持相近的材质精度和明暗关系，通过轮廓与配色区分：

- **荆棘守望者**：苔绿重甲、枝角头盔、古老巨斧和塔盾，沉静厚重。
- **蚀月巫妖**：骨面月冠、深紫礼袍、银蓝星环与法杖，冷光奥术。
- **灰烬之王**：完整黑曜石王冠、焦黑板甲、余烬裂隙与长剑，暗王座背景和橙金轮廓光。
- **荒野刽子手**：铁制处刑面具、粗砺皮毛与巨大处刑斧，荒野雾气背景。
- **黑甲统领**：黑钢封闭面甲、整齐军团盔甲、长戟与塔盾，暗堡背景；没有王冠或魔法光效。

人物外观、身份、首领称号与台词见 [人物设定](CHARACTERS.md)。五张首领的最终生成提示词及工具来源记录在 [Boss 立绘提示词](BOSS_ART_PROMPTS.md)。均使用内置 imagegen 独立生成，没有切换 CLI/API；原图和压缩图已检查主要轮廓、头冠、面具、武器及文字/UI 避免项。

## 游戏中的使用方式

选人画面展示完整职业立绘，角色头像通过 CSS 从同一图片裁显，保持面容一致。首领立绘使用 `object-fit: contain` 等比完整展示，保留王冠、枝角、法杖与武器，不为了填满画面裁掉轮廓。

五种首领登场均有姓名、称号、台词与应对提示；章节首领展示 2.8 秒，普通/宝库/精英关底展示 1.9 秒，点击、空格或回车均可跳过。展示期间战斗暂停。代码通过 `Battle.inputLocked` 即时锁定移动、技能和 `stepBattle` 推进，避免依赖每 100 ms 的界面快照产生短暂输入竞态；跳过按键阻止默认动作与冒泡，不同时释放技能。展示时间不计入压力宽限、狂暴或冷却。

### 原创强敌突入

`components/boss-arrival.tsx` 与 `components/boss-arrival.css` 负责独立演出，使用 `ag-cutin` 前缀隔离旧样式。演出采用原创格斗游戏的撞入节奏：斜向色块先切开画面，墨迹与速度线出现，立绘快速撞入后定格，随后显示「灾厄降临」或「强敌突入」、大字姓名和战术提示。没有使用其他游戏的商标、人物、招式名称或素材。

| 元素                       | 实现与职责                                               |
| -------------------------- | -------------------------------------------------------- |
| 五种首领立绘               | 本地 WebP，`contain` 等比容纳，复用原图且不裁切文件      |
| 斜切色块、速度线、衬底大字 | CSS 渐变、裁切和一次性位移，配色取当前首领主题色         |
| 墨迹与飞溅                 | 内联原创 SVG 路径和圆点，动画作用于外层容器              |
| 章节 Boss 冲击             | 短促画面震动、较强立绘撞入幅度；关底敌人没有同等强度震动 |
| 冲击声                     | 现有 Web Audio 合成的短低频音，不新增音频文件，尊重静音  |
| 展示进度                   | 底边细条，仅反映演出经过时间，不是首领生命条             |

暂停或切到后台时，展示倒计时和所有装饰 CSS 动画同时冻结，暂停期间跳过操作无效。开启 `prefers-reduced-motion` 后取消撞入、震动、速度线和光束动画，直接保留稳定构图。没有循环频闪或全屏闪白；键盘焦点能到达展示按钮，并能在结束后回到先前的可用控件。

### 战场布局、弹体与门

立绘只用于登场表现；当前战斗单位仍采用固定大小的简化俯视标记。技能移到战场右侧，底部仅保留 24px 经验条空间；队长世界坐标 `0.8` 在常见竖屏中约位于画面高度 82%。关底精英与章节 Boss 从旧版 `worldY = 0.332` 上移到 `0.008`，映射到画面上方约三成处，拉长可观察的玩家弹道。两者保持统一正交比例，不通过缩放伪造远近。

玩家普通射击是 Canvas 中真实向前飞行的弹体，而非命中后播放一条装饰光线：未碰到目标的弹体会继续飞过，副弹呈斜向扩散，穿透弹可经过多个目标，爆裂在有效命中处表现。弹速、宽度和数量应与当前词条一致；不能用视觉特效暗示额外命中或自动追踪。具体效果与伤害规则见 [游戏设计](GAME_DESIGN.md) 及当前战斗源码。

兵力大字紧贴队长上方并随队伍移动。宝箱、过门、升级和技能短提示位于角色上方约 103px，横向跟随时限制在画面内，与兵力数字分开。人数照实显示，兵力火力倍率沿用 `M = 1 + log2(1 + N / 12)`。门仍按队长中心判定；比例加减门首次进入预览后固定显示数值，避免玩家横移时数字跳动。

普通精英门组可以出现 `√x`，但不再按固定波次提供 `x²`。平方仅由通用史诗遗物禁术钥印（`square_key`）解锁；它使用现有图标与遗物卡系统，不新增位图。符合第二幕起条件的精英/章节 Boss 战后，有 12% 几率把钥印放入第三候选，普通奖励池和商店没有该遗物。持有后下一精英关必定开启一次试炼，每次远征限一次。

禁术试炼的前五道门依次为 −18%、÷1.30、−22%、÷1.35、−25%，红色门面覆盖全部可通行宽度，不画可躲避的空隙。第一道红门预览时，按当前兵力和实际过门逻辑（含取整、职业/遗物召唤）推演五步，统一固定全部红门值；百分比门显示最终扣除人数，后续不随人数跳动。五红门间隔 0.95 秒，最后一红门与平方三门间隔 1.35 秒，保持相同的提前预览和纵向速度；具体开始、到达与关底延后公式见 [游戏设计](GAME_DESIGN.md)。不添加额外硬控或追踪伤害提示。

最后一组 `x²`、`√x`、`+` 选择门可在五次损失全部结算前进入预览，但到达顺序始终位于第五道红门之后。平方道名义宽 0.18、实际判定宽 0.148 世界单位，约为门组总宽的 7.6%，位置可变，旁边有更宽的开方和加法道。不得把平方画成宽幅默认路线，或暗示试炼必定获得平方收益；必须先付出五次损失，再以队长中心判定所选通道。正负运算以颜色辅助，不能只靠绿色/红色区分；平方与开方不可画成容易混淆的乘除符号。

### HUD 与教程

关底精英和章节 Boss 的 HUD 使用全宽大血条，分别采用铜金与暗红色，名称、精确生命、阶段状态统一在屏幕上沿显示；不新增信息面板底色。血条有短暂受伤残影，并尊重减少动态效果的系统设置。具有半血强化的敌人显示 50% 刻度；灰烬之王没有该标记。吟唱提示位于血条下方，章节压力在边缘显示倒计时，触发时以扩散环和伤害反馈提示。

首次访问的图文教程使用本地 React/CSS 与内联 SVG 示意，展示横移、向前射击、门的运算、职业技能和构筑等机制，不依赖远程截图或额外教程位图。教程可以翻页，首次打开自动展示，之后从冒险手册/暂停入口重新查看；查看时暂停战斗。详尽分页内容见 [图文教程](TUTORIAL.md)，本资产清单只记录表现方式和素材来源。

曾试制六单位俯视图集，但因跨格、视角和透明通道未达到切片要求，没有接入。不能把试制图集当作已交付角色动画。
