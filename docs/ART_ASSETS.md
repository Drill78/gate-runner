## 人物与首领风格

职业统一要求：原创、完整身体、成年人物、透明背景、3D 微缩模型渲染质感、暖主光与冷轮廓光、细致但克制的金属/皮革/布料、无文字和 UI。骑士为钢甲、黄铜边、象牙战袍、绛红披风、长剑与盾；游侠为精灵女性、深绿兜帽、实用皮甲、弓与箭袋；法师为成熟人类男性、梅紫长袍、法杖与少量蓝金余烬。

十种强敌保持相近的材质精度和明暗关系，通过轮廓与配色区分：

- **荆棘守望者**：苔绿重甲、枝角头盔、古老巨斧和塔盾，沉静厚重。
- **蚀月巫妖**：骨面月冠、深紫礼袍、银蓝星环与法杖，冷光奥术。
- **灰烬之王**：完整黑曜石王冠、焦黑板甲、余烬裂隙与长剑，暗王座背景和橙金轮廓光。
- **荒野刽子手**：铁制处刑面具、粗砺皮毛与巨大处刑斧，荒野雾气背景。
- **黑甲统领**：黑钢封闭面甲、整齐军团盔甲、长戟与塔盾，暗堡背景；没有王冠或魔法光效。
- **咒刃骑士**：黑曜石甲、银边、克制的紫色裂隙与长剑，破败礼拜堂背景。
- **石誓巨像**：深灰石块与青铜束环组成的巨像，苔痕、双拳和琥珀胸口核心。
- **蛛巢主母**：甲胄女王上身与八足蛛躯，深色甲壳、宝石和蛛巢暗雾，不使用暴露服饰。

## 游戏中的使用方式

入口 `components/gate-entrance.tsx/css` 把同一张大门图按左右门扉显示，点击开启后以 CSS 向两侧展开并过渡到职业选择，尊重减少动态效果偏好。有可用存档时提供继续远征。选人画面展示职业立绘，角色头像通过 CSS 从同一图片裁显，保持面容一致。首领登场先将同一立绘放大作短暂近景，再拉出 `object-fit: contain` 的完整构图，显示王冠、枝角、法杖与武器；近景仅改变 CSS 镜头，不裁切源文件。

十种强敌登场均有姓名、称号、台词与应对提示；章节首领和普通/宝库/精英关底统一展示约 3 秒，点击、空格或回车均可跳过。展示期间战斗暂停。代码通过 `Battle.inputLocked` 即时锁定移动、技能和 `stepBattle` 推进，避免依赖每 100 ms 的界面快照产生短暂输入竞态；跳过按键阻止默认动作与冒泡，不同时释放技能。展示时间不计入压力宽限、狂暴或冷却。

永久图鉴复用相同十张强敌立绘；未击败时显示锁定标记，击败后显示档案、招式和次数。设置中的收藏入口提供图鉴与成就页签，已发现状态保存在当前浏览器，新开远征不清空；隐藏成就未达成前不公开条件。

### 原创强敌突入

`components/boss-arrival.tsx` 与 `components/boss-arrival.css` 负责独立演出，使用 `ag-cutin` 前缀隔离旧样式。演出采用原创格斗游戏的撞入节奏：斜向色块、墨迹与速度线先切入，立绘近景撞入并定格，约 0.72 秒后拉远，上下暗色遮幅同时退出；约 1.44 秒恢复完整轮廓，姓名与战术提示在约 1.52 秒前全部出现，余下时间保留稳定构图供阅读。章节 Boss 近景放大至 2.2 倍，关底敌人为 1.95 倍。没有使用其他游戏的商标、人物、招式名称或素材。

| 元素                       | 实现与职责                                                       |
| -------------------------- | ---------------------------------------------------------------- |
| 十种强敌立绘               | 本地 WebP，`contain` 等比容纳，复用原图且不裁切文件              |
| 斜切色块、速度线、衬底大字 | CSS 渐变、裁切和一次性位移，配色取当前首领主题色                 |
| 墨迹与飞溅                 | 内联原创 SVG 路径和圆点，动画作用于外层容器                      |
| 近景、拉远与章节 Boss 冲击 | 同一立绘放大后拉远，暗色遮幅退出；章节 Boss 近景更近并有短促震动 |
| 冲击声                     | 现有 Web Audio 合成的短低频音，不新增音频文件，尊重静音          |
| 展示进度                   | 底边细条，仅反映演出经过时间，不是首领生命条                     |

暂停或切到后台时，展示倒计时和所有装饰 CSS 动画（包括镜头与遮幅伪元素）同时冻结，暂停期间跳过操作无效。开启 `prefers-reduced-motion` 后取消近景、拉远、遮幅、撞入、震动、速度线和光束动画，直接显示完整立绘与全部文字。没有循环频闪或全屏闪白；键盘焦点能到达展示按钮，并能在结束后回到先前的可用控件。

### 战场布局、弹体与门

立绘用于入口、登场和图鉴；当前战斗单位仍由 Canvas 绘制差异化俯视轮廓。技能移到战场右侧，底部仅保留 24px 经验条空间；队长世界坐标保持 `0.8`，镜头范围扩为 `far = −0.68`、`near = 1.17`，在常见竖屏中约位于画面高度 77–79%。队长前方可见世界范围比原镜头增加 18.4%，提前预览由 1.25 秒延长到 1.5 秒。关底精英与章节 Boss 停留在 `worldY = −0.1`，约位于画面上方三成处。投影始终线性，物体体积不随远近变化，到达与碰撞线保持一致。左右各 3.5% 画宽用于低对比石墙与符文，装饰在单位后方，不覆盖门和文字。

玩家普通射击是 Canvas 中真实向前飞行的弹体，而非命中后播放一条装饰光线：未碰到目标的弹体会继续飞过，副弹呈斜向扩散，穿透弹可经过多个目标，爆裂在有效命中处表现。弹速、宽度和数量应与当前词条一致；不能用视觉特效暗示额外命中或自动追踪。具体效果与伤害规则见 [游戏设计](GAME_DESIGN.md) 及当前战斗源码。

兵力大字紧贴队长上方并随队伍移动。宝箱、过门、升级和技能短提示位于角色上方约 103px，横向跟随时限制在画面内，与兵力数字分开。人数照实显示，兵力火力倍率沿用 `M = 1 + log2(1 + N / 12)`。门仍按队长中心判定；比例加减门首次进入预览后固定显示数值，避免玩家横移时数字跳动。

普通精英门组可以出现 `√x`，但不按固定波次提供 `x²`。内部素材规则：通用史诗遗物禁术钥印（`square_key`）只在商店作为额外 500 金币商品提供，普通/精英奖励、升级与随机遗物池均不掉落；它使用现有图标与卡片系统，不新增位图。持有且未使用时，地图上原有可达精英节点会得到强化标记，进入该精英才消费本次机会并开启试炼。地图不新增独立秘境路线，结算仍按原节点推进一关。以下为实现用视觉规范，首次教程、未发现的隐藏成就和普通商品提示不提前公开试炼规则。

禁术试炼的前五道门依次为 −18%、÷1.30、−22%、÷1.35、−25%，红色门面覆盖全部可通行宽度，不画可躲避的空隙。第一道红门预览时，按当前兵力和实际过门逻辑（含取整、职业/遗物召唤）推演五步，统一固定全部红门值；百分比门显示最终扣除人数，后续不随人数跳动。五红门间隔 0.95 秒，最后一红门与平方三门间隔 1.35 秒，保持相同的提前预览和纵向速度；具体开始、到达与关底延后公式见 [游戏设计](GAME_DESIGN.md)。不添加额外硬控或追踪伤害提示。

最后一组 `x²`、`√x`、`+` 选择门可在五次损失全部结算前进入预览，但到达顺序始终位于第五道红门之后。平方道名义宽 0.18、实际判定宽 0.148 世界单位，约为门组总宽的 7.6%，位置可变，旁边有更宽的开方和加法道。不得把平方画成宽幅默认路线，或暗示试炼必定获得平方收益；必须先付出五次损失，再以队长中心判定所选通道。正负运算以颜色辅助，不能只靠绿色/红色区分；平方与开方不可画成容易混淆的乘除符号。

### HUD 与教程

关底精英和章节 Boss 的 HUD 使用全宽大血条，分别采用铜金与暗红色，名称、精确生命、阶段状态统一在屏幕上沿显示；不新增信息面板底色。血条有短暂受伤残影，并尊重减少动态效果的系统设置。普通半血强化显示 50% 刻度，灰烬之王按 70%/35% 分为三阶段，阶段变化与火环、陨火、焚风反馈匹配实际攻击。吟唱提示位于血条下方；敕令在战场显示绿色安全纵向通道与「集火打断 / 移入绿区」，红色危险填充只绘制在通道两侧，安全边界与实际世界坐标判定一致。章节压力另在边缘显示倒计时，触发时以扩散环和伤害反馈提示，不与可躲避的普通招式共用安全通道暗示。

图文教程使用本地 React/CSS 与内联 SVG 示意，展示横移、向前射击、门的运算、职业技能和构筑等机制，不依赖远程截图或额外教程位图。教程可以翻页，首次从入口启程后自动展示，关闭后记忆完成状态，之后从冒险手册/暂停入口重新查看；查看时暂停战斗。详尽分页内容见 [图文教程](TUTORIAL.md)，本资产清单只记录表现方式和素材来源。
