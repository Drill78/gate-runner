# 美术资产 v0.3

本轮沿用 v0.2 的职业立绘与城堡素材，主要更新竖屏布局、放大敌人、扩大可见范围，并增加旋转斧刃、摇摆星弹、交叉火弹、正面盾与仪式收缩环的 Canvas 表现。信息改为透明边缘文字，角色信息收进抽屉菜单。远近不改变单位大小；本版仍不是实际 3D 模型。

本版为原创中世纪奇幻气质。主界面使用完整人物立绘，战斗使用俯视 Canvas 单位；没有可编辑 3D 网格或骨骼资产。

| 文件                      | 用途           | 源图尺寸    | 在线 WebP 大小 |
| ------------------------- | -------------- | ----------- | -------------- |
| `public/art/citadel.webp` | 高塔与桥梁背景 | 1536 × 1024 | 158 KB         |
| `public/art/knight.webp`  | 骑士立绘与头像 | 1024 × 1536 | 272 KB         |
| `public/art/ranger.webp`  | 游侠立绘与头像 | 1024 × 1536 | 228 KB         |
| `public/art/mage.webp`    | 法师立绘与头像 | 1024 × 1536 | 294 KB         |

对应同名 PNG 为图像生成工具的原始输出，供后续美术使用。WebP 只进行等比缩放与格式压缩，人物立绘保留透明通道。页面引用本地 WebP，不依赖外部图片 CDN；图标来自现有 Lucide 库。

人物统一要求：原创、完整身体、成年人物、透明背景、3D 微缩模型渲染质感、统一暖主光与冷轮廓光、细致但克制的金属/皮革/布料、无文字和 UI。骑士为钢甲、黄铜边、象牙战袍、绛红披风、长剑与盾；游侠为精灵女性、深绿兜帽、实用皮甲、弓与箭袋；法师为成熟人类男性、梅紫长袍、法杖与少量蓝金余烬。

人物外观与身份详见 [人物设定](CHARACTERS.md)。选人画面以同一立绘作为完整形象，侧栏头像通过 CSS 裁显，不生成另一套不一致的人脸。

曾试制六单位俯视图集，但因跨格、视角和透明通道未达到切片要求，没有接入。战斗当前使用固定比例的简化俯视单位标记，不能把试制图集当作已交付角色动画。

后续真正 3D 的建议验收条件：glTF/GLB 文件、统一地面原点与尺寸、正交俯视相机、行走/攻击/受击/死亡短循环、统一阴影方向、手机端模型预算；碰撞仍按队长中心，视觉升级不改变门与预警的判定规则。
