# 灰烬之门 1.1 · 长夜无尽

以 1.0 为基础继续维护二维版本。3D 重构仍是独立新项目。

## 长夜远征

首次通关后开放。前十五层保持原有成长节奏；之后地图每十五层重新生成，关数持续增长，存档只保存当前轮地图。每五层首领之后出现三选一长夜契约：续燃伤害、扩大战阵、圣血恢复，后续开放焚印、深门知识与首领盟誓。契约与焚印收益在这次无尽远征内永久累积，普通／困难模式不继承数值优势。

20 层双守卫，25 层三段追猎，30 层双灰烬之王，35 层畸变，40 层融合，45 层三首领，50 层多段加冕；见过基础谱系后，按远征种子打乱后期组合。每种遭遇有预兆。每段最多三位首领；连战段间清场、短暂喘息、恢复少量生命；整场完成才发放战利品。

符文可重铸，保留武器、生命、契约、盟友；每层符文换取永存伤害，并补发基础构筑。商人首把钥匙 666，深门残章和前一重禁门共同解锁下一把钥匙，之后为 6666、66666 等。秘钥须实际通过禁门后才能推进层级。

后十五层敌人生命基于原末幕连续增长：16—30 层每层 5.8%，31—60 层每层 7.5%，61 层起每层 9.5%。无尽守关生命预算额外提高 40%；编队按人数平方根分配给成员，三段连战每段使用 70% 基准预算。收入每层增长 4.5%；成长契约每五层可提高 24% 伤害，重铸和盟友提供突破机会。敌人攻击增长低于生命，强化主要来自可躲避的机制组合。避免按玩家当前伤害动态加血。数值乘积有有限上界，地图、日志、实体数量保持有界。

## 灰烬史册

匿名旅人身份以随机密钥识别，名字可改，称号随每次远征留存。普通、困难分别收录胜利；无尽按最深关数、兵力等筛选。个人履历保留胜利、陨落和归还火种的记录。计时为实际交战用时，暂停、读卡和菜单时间不计入。
