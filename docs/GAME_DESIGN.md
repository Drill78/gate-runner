# 灰烬之门 · 游戏设计 v0.4

## 定位与主循环

原创中世纪奇幻 Gate Runner × 遗物构筑爬塔。一次远征选择一个职业，经过 12 层、3 幕，死亡即结束本局；职业始终可选，没有永久数值强化。以实时横移和自动射击做执行层，以地图路线、门的收益、战后三选一和补给分配做决策层。风格借鉴桌面角色扮演的誓约、精灵、巫妖和符文意象，没有移植其他作品的人物、规则文本或素材。

选职业 → 选择相连地图节点 → 战斗/非战斗房间 → 领取强化或处理事件 → 下一层 → 第 4/8/12 层首领。最后首领击杀直接胜利。中途可以查看构筑图鉴和暂停。

## 操作与空间

键盘按住 A/D 或 ←/→ 连续左右移动，松开停止；同时按两边则停止。空格放技能，P/Esc 暂停。鼠标点选任意横向位置，或触屏拖动；底部按钮释放职业技能。键盘速度为每秒 2.2 世界单位；鼠标/触屏每秒最多移动 4.8 单位，直接向指定位置移动，没有缓动拖尾。队伍跟随一个队长中心，横向没有离散赛道。战斗用真正的俯视等比例坐标：同一物体远处与近处大小相同、纵向速度相同。场地的左右边界固定，队伍在全宽范围内自由平移。

黄色队长标记用于过门与攻击预警判定；后方小队是兵力的视觉代表，最多绘制 24 名跟随者，实际兵力没有 999 上限。兵力数字以大号描边文字显示在队伍上方，并随队长横移。兵力、攻击强度、齐射伤害和每秒火力分别说明，公式见 [数值文档](BALANCE.md)。

进入远征后采用整屏竖屏战场，桌面限宽 560px。左上角显示角色入口和生命/护盾，右上角显示金币与暂停，边缘显示波次、章节压力倒计时与细经验条，信息没有大块背景。角色立绘、装备、构筑、图鉴、路线和音效放入二级菜单；打开菜单暂停战斗，关闭后恢复。安全区适配刘海和底部手势区域。战场预留底部操作空间，避免队伍与拇指按钮重叠。

相机提前展示尚未进入射程的目标，最多提前 1.25 秒，远处略淡、进入射程后正常显示；提前可见不允许提前攻击。敌人保持固定体积，普通敌人绘制尺度为士兵的 1.9 倍，首领为 3 倍，并扩大相应目标宽度。名称、血量和弹幕用描边保证辨认。

## 门：两道或三道、不等宽

每组门只有一次结算机会，以队长中心进入的区间为准；门之间有窄缝，擦过门缝没有效果。正向门以绿色加法和蓝色乘法区分，红色代表减法/除法。视觉上直接显示运算符和数值，不能只靠颜色判断。

第 1 波双门；后续门组有 60% 概率三门。双门分割位置可偏左或偏右；三门中央奖励更高但通行面积不同。负向门组合会要求选择损失较小的一边，也可通过门缝舍弃整组收益。

基础加法量 A = 6 + floor((楼层−1)×0.65)。候选组合是 [+A, ×1.18]、[+(A+4), ×1.28]、[−max(4,A−1), ÷1.2]、[+(A+1), ×1.12]，左右随机交换。三门中间为 ×1.36/1.40/1.44，随幕变化。首层第一门固定用第一组，便于起步。

先应用运算和门强化，再添加职业/遗物召唤，最后保护最少 1 人；正向门再给誓言回响护盾。乘除向下取整。法师、星界契约和王者战旗在负向门也会召唤。

## 战斗内容

| 对象     | 行为                             | 处理重点               |
| -------- | -------------------------------- | ---------------------- |
| 骸骨先锋 | 持续接近，漏掉会冲击队伍         | 保持瞄准，提前打掉     |
| 幽林弓手 | 锁定当前位置，红区预警后射击     | 在输出与躲预警间移动   |
| 黑甲盾卫 | 生命 ×1.45、护甲 22%             | 用武器、暴击、回响突破 |
| 精英斥候 | 精英房额外出现，形成双目标压力   | 技能与弹射更有价值     |
| 荆棘地带 | 越界时检查队长位置               | 提前移出范围           |
| 补给宝箱 | 必须在越界前击破                 | +22 金币、+4 兵力      |
| 兵装秘匣 | 必须持续攻击击破                 | 武器等级 +1，最高 10   |
| 关底统领 | 中央附近停留，交替散斧与锁定攻击 | 保持瞄准并穿过弹隙     |

宝库中的三只箱子全部提升武器。普通房第 3 波为补给，第 6 波为兵装。宝箱到期直接失去奖励；不能仅经过领取。击杀敌人 +4 金币，并得到先锋 6、弓手 8、盾卫 10、关底统领 20、幕首领 45 经验；击杀时直接显示奖励。完成普通/宝库 +28、精英 +55、首领 +80，再加渡鸦钱币奖励。漏怪没有经验或金币，而且仍会造成生命和兵力损失。

### 经验与职业防御

局内 Lv1–12，升到下一级需要 `30 + 14 × (当前等级−1)` 经验。每级提供基础攻击成长 +2%（按等级线性累计），最大生命与当前生命各 +2；升级不回满血，也不给额外三选一。三选一仍是战后构筑的核心，等级为主动清怪提供稳定小额回报。经验随本局存档，死亡或新开局归零。

生存依赖走位、职业技能、护盾、护甲和生命回复。骑士保留初始护甲与护盾，主动技能补盾并增加伤害；法师可通过符文护体获得开战护盾。来伤先计算护甲，再消耗护盾，最后扣生命。护盾完整吸收时不损兵；章节压力另有不损兵规则。

### 五种首领与登场

荆棘守望者、蚀月巫妖、灰烬之王、荒野刽子手、黑甲统领均有独立立绘、称号、台词和应对提示。立绘完整等比容纳在展示区域内，保留头冠与武器轮廓。章节首领登场展示 2.8 秒，普通/宝库/精英关底展示 1.9 秒，均可点击跳过。展示期间即时锁定全部移动、技能和战斗推进，计时与冷却暂停，展示耗时不计入狂暴或章节压力宽限。

普通与宝库关底为荒野刽子手，精英关底为黑甲统领。两者每 3.2 秒轮转一次攻击：五向散斧与锁定重击交替；低于半血后，散斧再追加一轮三向追斧。它们没有章节压力，靠更高生命和连续攻击限制低输出构筑。

### 第 1 幕：荆棘边境

废墟之中，古老的誓言尚未熄灭。该幕 8 波，首领为 **荆棘守望者**。交替投掷五向散斧、举起正面盾牌并锁定玩家重击。玩家可从弹隙穿过；举盾 3.2 秒内正面伤害降低 70%，移到侧翼仍可持续射击。生命低于 50% 后散斧变七向，飞行加快。

### 第 2 幕：月蚀回廊

月光消逝的地方，回响仍在低语。该幕 10 波，首领为 **蚀月巫妖**。横向缓慢漂移，从法环放出两批错位的魔法星弹，分别七枚和六枚。星弹沿摇摆曲线飞来，玩家需要读清两批落点，不能只躲一次固定红框。生命低于 50% 后缩短两批间隔。

### 第 3 幕：余烬王座

最后一道门后，灰烬正等待新王。该幕 12 波，首领为 **灰烬之王**。常规技能在交叉焚风与末日敕令之间交替：前者从两侧放出交错火弹；后者吟唱 3.2 秒，期间造成相当于首领最大生命 5.5% 的实际伤害即可打断。吟唱条显示剩余打断值，未打断则受到全屏伤害；应在持续齐射与职业技能间安排爆发。王权震荡属于下述独立章节压力，不占用这两种常规技能的轮转。

首领约登场 0.9 秒首次出招；章节首领轮转间隔 4.4 秒，普通/精英关底为 3.2 秒。吟唱完成后重新计时，成功打断额外延后 1 秒。每个首领在登场 22 秒后进入狂暴，之后生成的常规攻击伤害乘 1.75；章节压力不再另乘狂暴。同一批弹幕至多造成一次伤害，错开的两批分别结算。关底仍可击杀，没有强制时间失败。

### 章节压力

只有第 4/8/12 层的章节首领具有独立周期性全屏压力。首次冲击从首领登场开始，经过宽限时间结算，之后固定间隔触发；伤害逐次提高，不可走位躲避或用攻击打断，但护甲与护盾照常生效，生命受伤也不损兵。压力与常规弹幕、吟唱并行，目的是要求输出和续航共同成长。

| 章节   | 名称     | 首次宽限 | 后续间隔 | 首次原始伤害 | 每次追加 |
| ------ | -------- | -------- | -------- | ------------ | -------- |
| 第一幕 | 荆棘蚀血 | 22 秒    | 8 秒     | 10           | +3       |
| 第二幕 | 蚀月凋零 | 17 秒    | 7 秒     | 16           | +4       |
| 第三幕 | 王权震荡 | 17 秒    | 6.5 秒   | 20           | +5       |

例如第三幕压力的原始伤害依次为 20、25、30……，不乘首领常规伤害或狂暴倍率。界面显示下一次压力倒计时，冲击时给出全屏反馈。在结算截止帧击败首领可以阻止该次压力；死亡则立即结束远征。

## 地图与房间

每幕第 1 层为普通/精英/事件组合，第 2 层为普通/宝库/精英组合，第 3 层为营火/商店/事件组合，第 4 层固定首领。路线只连接下一层相同列或相邻列；首领节点汇合，下一幕重新展开。

- **普通战斗**：基础风险、三选一。
- **精英哨站**：小怪与宝箱生命 ×1.24、额外斥候、更多金币；黑甲统领使用独立关底血量，奖励第二个候选优先非普通遗物。
- **遗落宝库**：小怪与宝箱生命 ×0.85、三只武器箱；关底仍为普通强度的荒野刽子手，战后有三选一。
- **营火**：恢复最大生命 40% 或武器 +1，二选一，不额外给遗物。
- **渡鸦商店**：每种商品每房限购一次；离开后推进一层。
- **祭坛事件**：失去 18 生命换随机职业优先遗物（生命必须大于 18）；支付 35 金币招募 22 人；或获得 12 金币离开。三选一。

## 遗物与 build

全部 25 项遗物、叠层与公式见 [数值设计](BALANCE.md)。三位原创人物与六套流派见 [人物与流派](CHARACTERS.md)。奖励不重复、排除已满层遗物；第一候选优先本职业，精英/首领第二候选优先稀有或史诗，池耗尽则回退可用池。这是候选资格倾向，不是隐藏稀有度权重系统。

六个方向为：骑士誓盾锋刃/荆冠远征；游侠猎王穿心/月影连锁；法师秘火蚀骨/星契回响。后两类固定附伤体系需要直击成长支持，不能宣传纯反伤或纯灼烧必过。

## 美术和后续 3D

三职业完整立绘与五种首领立绘使用生成式图像，按中世纪装备、统一材质光照制作。职业立绘保留透明背景，首领立绘使用暗色氛围背景，并用于首领登场展示。界面以墨绿石材、深蓝灰阴影和黄铜强调色呈现，职业头像从同一立绘裁显，保证一致性。在线使用本地 WebP，无远程字体、图片或游戏 API 依赖。

本版是 Canvas 2D 俯视战斗，角色立绘具有 3D 渲染质感；不包含可编辑模型、骨骼或真正 3D 场景。未来可保持当前世界坐标和正交相机，替换为 glTF 单位、短循环行走/攻击动画、实时接触阴影、分幕石材地形。不要重新引入透视投影导致远近速度错觉。

## 存档、版本与已知边界

关卡间自动存当前浏览器；战斗刷新回到入房前存档，不能从战斗中间恢复。新开局清除旧远征；死亡清空本局，保留最远层数。v0.4 沿用 v0.3 的格式 v3，无需新增迁移，并继续使用 v0.2 的存储键；旧 v2 存档仍可自动迁移、保留生命装备路线并设经验为零，不追补历史经验。v1 远征仍不读取，最高记录保留。不提供云同步、账号、多人或永久天赋。

当前是可试玩的完整十二层切片。怪物模型、攻击动画、更多房间事件及独立机制的新职业属于后续内容。实际大陆网络连通性和触屏手感需要试玩反馈；部署方案见 [部署说明](DEPLOYMENT.md)。
