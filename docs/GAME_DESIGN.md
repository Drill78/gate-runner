# 灰烬之门 · 游戏设计 v0.5

## 定位与主循环

原创中世纪奇幻 Gate Runner × 遗物构筑爬塔。一次远征选择一个职业，经过 12 层、3 幕，死亡即结束本局；职业始终可选，没有永久数值强化。以实时横移和自动射击做执行层，以地图路线、门的收益、战后三选一和补给分配做决策层。风格借鉴桌面角色扮演的誓约、精灵、巫妖和符文意象，没有移植其他作品的人物、规则文本或素材。

选职业 → 选择相连地图节点 → 战斗/非战斗房间 → 领取强化或处理事件 → 下一层 → 第 4/8/12 层首领。最后首领击杀直接胜利。中途可以查看构筑图鉴和暂停。

v0.5 将自动攻击改为真实向前飞行的玩家弹幕，新增弹幕构筑与定向购买；调整主角和关底敌人的停留位置，扩展按兵力缩放的加减门，并加入由禁术钥印解锁、每次远征限一次的精英禁术试炼。表现层加入格斗游戏节奏的原创强敌突入、全宽大血条、右侧技能按钮和首次访问图文教程。本文保留旧版难度曲线参数，并单独标注历史模拟结果；新版不能直接沿用旧命中模型的胜率。

## 操作与空间

键盘按住 A/D 或 ←/→ 连续左右移动，松开停止；同时按两边则停止。空格或战场右侧按钮释放职业技能，P/Esc 或右上角入口暂停。鼠标点选任意横向位置，或触屏拖动。键盘速度为每秒 2.2 世界单位；鼠标/触屏每秒最多移动 4.8 单位，直接向指定位置移动，没有缓动拖尾。队伍跟随一个队长中心，横向没有离散赛道。战斗用真正的俯视等比例坐标：同一物体远处与近处大小相同、纵向速度相同。场地的左右边界固定，队伍在全宽范围内自由平移。

黄色队长标记用于过门与攻击预警判定；后方小队是兵力的视觉代表，最多绘制 24 名跟随者，实际兵力没有 999 上限。兵力数字以大号描边文字紧贴队伍上方，并随队长横移。宝箱、过门、升级和技能的短提示显示在角色上方约 103px，横向跟随但在画面边缘限制位置，避免遮挡兵力或被截断。兵力、攻击强度、齐射伤害和每秒火力分别说明；兵力带来的火力倍率统一沿用 `M = 1 + log2(1 + N / 12)`，其中 `N` 是实际兵力，人数仍按门运算。基础公式见 [数值文档](BALANCE.md)。

进入远征后采用整屏竖屏战场，桌面限宽 560px。左上角显示角色入口和生命/护盾，右上角显示金币与暂停，边缘显示波次、章节压力倒计时与细经验条，信息没有大块背景。角色立绘、装备、构筑、图鉴、路线和音效放入二级菜单；打开菜单暂停战斗，关闭后恢复。安全区适配刘海和底部手势区域。技能移到右侧后，底部仅保留细经验条所需的 24px 空间（`VIEW.controlSpace = 24`）；队长世界坐标仍为 `playerY = 0.8`，映射到常见竖屏高度约 82%，更靠近画面下方。

首次打开且尚未看过教程时，选人页自动弹出可翻页的图文教程；完成或关闭后在当前浏览器记录已读状态。之后可从暂停菜单或冒险手册入口重新查看。战斗中打开教程仍计入暂停，关闭教程恢复此前状态；若从已暂停的菜单进入，返回后仍需选择继续战斗。教程解释横移、向前弹幕与打空、门、职业技能、构筑和关底压力，不接管玩家操作。

相机最多提前 1.25 秒展示即将进入战斗的目标，预览状态略淡；可见不代表已经可以命中，尚未到开始时刻的目标不能被玩家弹体提前结算。敌人保持固定体积，普通敌人绘制尺度为士兵的 1.9 倍，首领为 3 倍，并扩大相应目标宽度。名称、血量和弹幕用描边保证辨认。关底精英与章节 Boss 的停留点从旧版 `worldY = 0.332` 上移到 `0.008`（`progress` 上限为 0.12），在 900px 高战场中约为画面高度 30.1%，给向前弹幕留下更长、可观察的飞行通道。

### 关底精英与章节 Boss 的大血条

普通、宝库和精英房间末尾的强敌统称「关底精英」（荒野刽子手、黑甲统领）；第 4/8/12 层的守护者称为「章节 Boss」。两者登场展示结束后，在屏幕上沿出现贯穿战场宽度的大血条，关底精英为铜金色、章节 Boss 为暗红色，明确标注类别、名称和当前生命/最大生命。血条随实际受伤变化，并保留短暂的受伤残影。具有半血强化的敌人显示 50% 刻度，并按当前行为显示交战中、第二阶段、正面举盾、正在吟唱或狂暴；没有半血机制的灰烬之王不会被误标为第二阶段。击败或离开战斗后血条隐藏。姓名与精确血量从怪物周围移到大血条，减少场内文字重叠；吟唱提示排在大血条下方。

## 门：两道或三道、不等宽

每组门只有一次结算机会，以队长中心进入的区间为准；普通选择门之间有窄缝，擦过门缝没有效果。正向门以绿色加法和蓝色乘法/平方区分，红色代表减法/除法/开方。禁术试炼前五道红门覆盖全宽，没有可绕开的门缝。视觉上直接显示运算符和数值，不能只靠颜色判断。

普通门组的第 1 波为双门；后续有 60% 概率三门。双门分割位置可偏左或偏右；三门中央奖励更高但通行面积不同。普通负向门组合会要求选择损失较小的一边，也可通过门缝舍弃整组收益；禁术试炼的五道全宽红门不适用该绕过方式。

旧版固定数值的基础加法量 A = 6 + floor((楼层−1)×0.65)。候选组合是 [+A, ×1.18]、[+(A+4), ×1.28]、[−max(4,A−1), ÷1.2]、[+(A+1), ×1.12]，左右随机交换。三门中间为 ×1.36/1.40/1.44，随幕变化。该表保留为历史基础曲线；首层第一门继续用第一组，便于起步。

v0.5 从第 2 层（代码 `floor >= 1`）开始，让加法门和减法门的数量随队伍兵力按比例缩放。门组首次进入预览区时读取当时兵力并固定整组显示值，之后不会因受伤、招募或其他收益而在玩家面前跳动；真正通过时结算固定门值，职业和遗物附加效果仍在过门时计算。第 1 层（`floor < 1`）保留原数值；乘除、平方和开方不参与这次加减门数值缩放。

开发公式中 `floor` 从 0 开始，`squad` 是首次预览时的兵力，`g.value` 是生成时的原始门值：

```text
depth = min(8, floor)
base = 6 + ⌊floor × 0.65⌋
variation = clamp(g.value / base, 0.85, 1.25)
加法比例 = 0.14 + 0.01 × depth
减法比例 = 0.12 + 0.02 × depth
raw = max(g.value, squad × 对应比例 × variation)
step = 10 ^ max(0, ⌊log10(raw)⌋ − 1)
固定门值 = max(g.value, round(raw / step) × step)
```

上述取整保留约两位有效数字，小于 100 的数量按整数显示，并且最终门值至少等于原值。基础加法比例从第 2 层的 15% 增至最高 22%，减法从 14% 增至最高 28%，再乘每道门的变化系数。公式只用于生成固定整数门值，游戏内提示直接展示实际运算和数值。

普通精英波次可以出现开方门，但不再固定生成平方门。`√x` 先得到 `floor(sqrt(当前兵力))`，不是固定减员或除二；它与同组其他门仍共享一次结算机会。`x²` 只会出现在下述禁术试炼的最后选择门中，必须先取得专用遗物并承担试炼代价。

先应用运算和对应门强化，再添加职业/遗物召唤，最后通过安全兵力限制保护最少 1 人；正向门再给誓言回响护盾。乘除及开方向下取整。平方门属于正向门，骑士持有誓言回响时照常获得过门护盾；法师本职召唤、星界契约和王者战旗在平方、开方及其他负向门后也照常结算。平方运算同样受安全整数上界保护，不产生无穷兵力。

### 禁术钥印与一次性试炼

新增通用史诗遗物 **禁术钥印**（`square_key`），最多 1 层。它不进入普通遗物池、随机商店或定向商店。仅在精英或章节 Boss 战后产生选卡奖励时，奖励结算后 `run.floor >= 4`，且尚未持有钥印、未开启过试炼，才有 12% 几率成为第三个候选；普通池不足三项时追加到剩余候选中，玩家仍需主动选择它。首次符合这一层数条件的是第 4 层章节 Boss 获胜后的奖励，此时远征已进入第二幕。没有战后选卡的最终胜利不额外发放候选。

持有禁术钥印且本次远征尚未开启过试炼时，进入下一间精英房必定在原关底前插入禁术试炼，不再做第二次触发概率判定。每次远征最多开启一次；开启机会与最终是否穿过平方道分开，错失平方门不会返还一次试炼。

试炼先依次通过五道必须承受的全宽红门，再面对一组高风险三选门，最后迎战黑甲统领：

| 顺序 | 红门运算 | 定值与结算                                           |
| ---- | -------- | ---------------------------------------------------- |
| 1    | −18%     | 试炼统一推演时，按本步之前的预计兵力向上取整扣除人数 |
| 2    | ÷1.30    | 到达时向下取整，再结算职业/遗物召唤                  |
| 3    | −22%     | 试炼统一推演时，按本步之前的预计兵力向上取整扣除人数 |
| 4    | ÷1.35    | 到达时向下取整，再结算职业/遗物召唤                  |
| 5    | −25%     | 试炼统一推演时，按本步之前的预计兵力向上取整扣除人数 |

第一道红门进入预览时，复制当前玩家状态，按实际 `applyGate` 逻辑连续推演五道门：每个百分比扣兵值取 `max(1, ceil(本步预计兵力 × 比例))`，再把本步运算、取整与职业/遗物召唤计入下一步预计兵力。五道红门的值在这一次推演中统一固定，之后不重新读取各门预览时的人数，也不套用普通加减门的楼层缩放；实际过门时仍逐道结算固定门值。

不计取整与召唤，五次运算的参考保留率为 `0.82 / 1.30 × 0.78 / 1.35 × 0.75 ≈ 27.3%`，即付出约 72.7% 兵力。实际人数包含整数结算与法师/遗物召唤，27.3% 不是固定结算保证。试炼不额外加入硬控或追踪伤害，压力来自五次必付的兵力代价和随后极窄的平方通道。

时序按 `lib/combat.ts` 的实际生成逻辑，以普通波次所有实体的最晚到达时间为 `L`，试炼起点为 `T`：

```text
T = L + VIEW.previewSeconds + 0.25 = L + 1.50 秒
红门 i 的 start = T + (i − 1) × 0.95 秒，i = 1…5
平方三门 start = T + 5 × 0.95 + 0.40 = T + 5.15 秒
各门 arrival = start + 本幕 travel
关底统领 finalStart = 平方三门 arrival + 1.00 秒
```

因此第一道红门预览在普通波次最晚到达后的 0.25 秒开始；五道红门开始与到达均相隔 0.95 秒，最后一红门与平方三门之间的开始/到达间隔为 1.35 秒。第二幕 `travel = 3.5` 秒，第三幕为 3.1 秒；所有门保留同样的 1.25 秒提前预览。平方三门可能在第五道红门结算前已可见，但只能在五次损失之后到达队长；关底开始时间也随试炼整体后移。

最后的三门包含极窄 `x²`、较宽 `√x` 和常规 `+`，位置可变。平方道名义宽 0.18 世界单位，扣除两侧门缝后的判定宽为 0.148，约占门组总宽的 7.6%；五道红门的损失已先发生，仍可能因瞄准不准错过平方收益。成功通过才将当时兵力平方，随后照常结算过门召唤与正向门护盾，最后进入精英关底战斗。

## 战斗内容

### 玩家向前弹幕

自动攻击按职业射速持续从队伍前方发射真实弹体。主弹向前飞行；散射副弹沿固定斜角向两侧飞行，不自动追踪目标。敌人或宝箱与弹体的飞行路径相交才发生命中，路径未经过目标就会打空或从两侧飞过。移动改变后续发射位置，已经发出的弹体继续沿原方向前进，不能把瞄准后的一次瞬时伤害当作新版攻击模型。

命中按弹体与移动目标的连续路径检查，避免高速弹体在两帧之间穿过目标却漏判。没有穿透时弹体在首次有效命中后消失；穿透使同一弹体继续向前，但不会重复命中同一个目标。未命中的弹体飞出场地或达到寿命上限后清除。职业主动技能仍保留原有护盾、增伤或范围打击功能，不要求每种技能都转换为普通射击弹体。

新增通用词条如下；具体叠层公式以 `lib/game.ts` 的 `RELICS/stats` 为准，弹体碰撞、伤害触发和范围以 `lib/combat.ts` 为准。

| 遗物     | 最大层数 | 弹幕效果                                                          |
| -------- | -------: | ----------------------------------------------------------------- |
| 双翼符印 |        2 | 每层增加左右一对斜向副弹，每枚为主弹 50% 伤害                     |
| 贯阵尖锥 |        3 | 每层多穿透 1 个目标，每次穿透后保留 75% 伤害                      |
| 疾风导环 |        2 | 每层弹速 +25%                                                     |
| 炼金火芯 |        3 | 命中时向附近其他目标造成每层 30% 的弹体伤害，受击目标分别计算防御 |
| 铅铸重弹 |        2 | 每层主弹伤害 +25%、攻击速度 −10%                                  |
| 聚能刻印 |        2 | 每层弹体半径 +30%、伤害 +10%                                      |
| 终猎契印 |        2 | 对生命低于 30% 的目标，每层额外伤害 +20%                          |

基础弹速为每秒 1.7 世界单位，基础碰撞半径为 0.025 世界单位；弹速、弹体宽度、散射数量和穿透次数分别改变命中机会，不应只把它们换算成无条件 DPS 倍率。显示的齐射伤害与每秒火力是构筑参考，实战输出还受飞行时间、目标位置、打空和防御机制影响。

| -------- | ------------------------------ | ---------------------- |
| 骸骨先锋 | 持续接近，漏掉会冲击队伍       | 保持瞄准，提前打掉     |

| 补给宝箱 | 必须在越界前击破               | +22 金币、+4 兵力      |

宝库中的三只箱子全部提升武器。普通房第 3 波为补给，第 6 波为兵装。宝箱到期直接失去奖励；不能仅经过领取。击杀敌人 +4 金币，并得到先锋 6、弓手 8、盾卫 10、关底统领 20、幕首领 45 经验；击杀时直接显示奖励。完成普通/宝库 +28、精英 +55、首领 +80，再加渡鸦钱币奖励。漏怪没有经验或金币，而且仍会造成生命和兵力损失。

### 经验与职业防御

局内 Lv1–12，升到下一级需要 `30 + 14 × (当前等级−1)` 经验。每级提供基础攻击成长 +2%（按等级线性累计），最大生命与当前生命各 +2；升级不回满血，也不给额外三选一。三选一仍是战后构筑的核心，等级为主动清怪提供稳定小额回报。经验随本局存档，死亡或新开局归零。

生存依赖走位、职业技能、护盾、护甲和生命回复。骑士保留初始护甲与护盾，主动技能补盾并增加伤害；法师可通过符文护体获得开战护盾。来伤先计算护甲，再消耗护盾，最后扣生命。护盾完整吸收时不损兵；章节压力另有不损兵规则。

### 五种首领与登场

荆棘守望者、蚀月巫妖、灰烬之王、荒野刽子手、黑甲统领均有独立立绘、称号、台词和应对提示。v0.5 使用原创格斗游戏节奏的突入演出：斜向色块切入、墨迹飞溅、短速度线、立绘撞入后定格、大字姓名与提示依次显现。立绘按原比例容纳，不改变图片本身；章节 Boss 加强短促震动和低频冲击，关底敌人的演出稍短。装饰由独立组件的 CSS/SVG 生成，不使用其他游戏商标、人物或招式素材。

章节首领展示 2.8 秒，普通/宝库/精英关底展示 1.9 秒，均可点击、空格或回车跳过。展示期间 `Battle.inputLocked` 即时锁定全部移动、技能和战斗推进，避免界面快照延迟产生输入竞态；跳过按键会阻止默认动作与冒泡，不同时释放技能。计时与冷却暂停，展示耗时不计入狂暴或章节压力宽限。暂停菜单或切后台时，展示倒计时和装饰动画也冻结，暂停期间不能跳过；恢复后继续剩余演出。系统要求减少动态效果时直接显示稳定构图，无震动或速度线；没有循环频闪或全屏闪白。冲击声遵循静音设置。

普通与宝库关底为荒野刽子手，精英关底为黑甲统领。两者每 3.2 秒轮转一次攻击：五向散斧与锁定重击交替；低于半血后，散斧再追加一轮三向追斧。它们没有章节压力，靠更高生命和连续攻击限制低输出构筑。

### 第 1 幕：荆棘边境

废墟之中，古老的誓言尚未熄灭。该幕 8 波，首领为 **荆棘守望者**。交替投掷五向散斧、举起正面盾牌并锁定玩家重击。玩家可从弹隙穿过；举盾 3.2 秒内正面伤害降低 70%，移到侧翼仍可持续射击。生命低于 50% 后散斧变七向，飞行加快。

### 第 2 幕：月蚀回廊

月光消逝的地方，回响仍在低语。该幕 10 波，首领为 **蚀月巫妖**。横向缓慢漂移，从法环放出两批错位的魔法星弹，分别七枚和六枚。星弹沿摇摆曲线飞来，玩家需要读清两批落点，不能只躲一次固定红框。生命低于 50% 后缩短两批间隔。

### 第 3 幕：余烬王座

最后一道门后，灰烬正等待新王。该幕 12 波，首领为 **灰烬之王**。常规技能在交叉焚风与末日敕令之间交替：前者从两侧放出交错火弹；后者吟唱 3.2 秒，期间造成相当于首领最大生命 5.5% 的实际伤害即可打断。吟唱条显示剩余打断值，未打断则受到全屏伤害；应在持续齐射与职业技能间安排爆发。王权震荡属于下述独立章节压力，不占用这两种常规技能的轮转。

首领约登场 0.9 秒首次出招；章节首领轮转间隔 4.4 秒，普通/精英关底为 3.2 秒。吟唱完成后重新计时，成功打断额外延后 1 秒。每个首领在登场 22 秒后进入狂暴，之后生成的常规攻击伤害乘 1.75；章节压力不再另乘狂暴。同一批弹幕至多造成一次伤害，错开的两批分别结算。关底仍可击杀，没有强制时间失败。

### 章节压力

只有第 4/8/12 层的章节首领具有独立周期性全屏压力。首次冲击从首领登场开始，经过宽限时间结算，之后固定间隔触发；伤害逐次提高，不可走位躲避或用攻击打断，但护甲与护盾照常生效，生命受伤也不损兵。压力与常规弹幕、吟唱并行，目的是要求输出和续航共同成长。

| 章节   | 名称     | 首次宽限 | 后续间隔 | 首次原始伤害 | 每次追加 |
| ------ | -------- | -------- | -------- | ------------ | -------- |
| 第一幕 | 荆棘蚀血 | 22 秒    | 8 秒     | 10           | +3       |
| 第二幕 | 蚀月凋零 | 17 秒    | 7 秒     | 16           | +4       |
| 第三幕 | 王权震荡 | 17 秒    | 6.5 秒   | 20           | +5       |

例如第三幕压力的原始伤害依次为 20、25、30……，不乘首领常规伤害或狂暴倍率。界面显示下一次压力倒计时，冲击时给出全屏反馈。在结算截止帧击败首领可以阻止该次压力；死亡则立即结束远征。

## 地图与房间

每幕第 1 层为普通/精英/事件组合，第 2 层为普通/宝库/精英组合，第 3 层为营火/商店/事件组合，第 4 层固定首领。路线只连接下一层相同列或相邻列；首领节点汇合，下一幕重新展开。

- **普通战斗**：基础风险、三选一。
- **精英哨站**：小怪与宝箱生命 ×1.24、额外斥候、更多金币；黑甲统领使用独立关底血量，奖励第二个候选优先非普通遗物。
- **遗落宝库**：小怪与宝箱生命 ×0.85、三只武器箱；关底仍为普通强度的荒野刽子手，战后有三选一。
- **营火**：恢复最大生命 40% 或武器 +1，二选一，不额外给遗物。
- **渡鸦商店**：每种商品每房限购一次；离开后推进一层。
- **祭坛事件**：失去 18 生命换随机职业优先遗物（生命必须大于 18）；支付 35 金币招募 22 人；或获得 12 金币离开。三选一。

## 遗物与 build

当前共 33 项遗物，包括原有 25 项、上表 7 项通用弹幕遗物，以及特殊来源的禁术钥印。完整条目、可叠层上限与当前效果以 `lib/game.ts` 为准；完整公式见 [数值设计](BALANCE.md)。三位原创人物与原有六套职业方向见 [人物与流派](CHARACTERS.md)，新版词条与商店货品见 [构筑目录](BUILD_CATALOG.md)。常规奖励不重复、排除已满层遗物；第一候选优先本职业，精英/首领第二候选优先稀有或史诗，池耗尽则回退可用池。这些属于候选资格倾向；禁术钥印另外使用前述限定来源的 12% 第三候选规则。

## 美术和后续 3D

三职业完整立绘与五种首领立绘使用生成式图像，按中世纪装备、统一材质光照制作。职业立绘保留透明背景，首领立绘使用暗色氛围背景，并用于首领突入展示。v0.5 复用现有位图，用独立 CSS/SVG 叠加墨迹、色块和速度线；玩家弹体、命中与爆裂由 Canvas 绘制，教程采用原生图文示意。界面以墨绿石材、深蓝灰阴影和黄铜强调色呈现，职业头像从同一立绘裁显，保证一致性。在线使用本地 WebP，无远程字体、图片或游戏 API 依赖。

本版是 Canvas 2D 俯视战斗，角色立绘具有 3D 渲染质感；不包含可编辑模型、骨骼或真正 3D 场景。未来可保持当前世界坐标和正交相机，替换为 glTF 单位、短循环行走/攻击动画、实时接触阴影、分幕石材地形。不要重新引入透视投影导致远近速度错觉。
