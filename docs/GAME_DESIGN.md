# 灰烬之门 · 游戏设计 v0.2

## 定位与主循环

原创中世纪奇幻 Gate Runner × 遗物构筑爬塔。一次远征选择一个职业，经过 12 层、3 幕，死亡即结束本局；职业始终可选，没有永久数值强化。以实时横移和自动射击做执行层，以地图路线、门的收益、战后三选一和补给分配做决策层。风格借鉴桌面角色扮演的誓约、精灵、巫妖和符文意象，没有移植其他作品的人物、规则文本或素材。

选职业 → 选择相连地图节点 → 战斗/非战斗房间 → 领取强化或处理事件 → 下一层 → 第 4/8/12 层首领。最后首领击杀直接胜利。中途可以查看构筑图鉴和暂停。

## 操作与空间

键盘按住 A/D 或 ←/→ 连续左右移动，松开停止；同时按两边则停止。空格放技能，P/Esc 暂停。鼠标点选任意横向位置，或触屏拖动；屏幕两侧按钮也支持按住移动。队伍跟随一个队长中心，横向没有离散赛道。战斗用真正的俯视等比例坐标：同一物体远处与近处大小相同、纵向速度相同。场地的左右边界固定，队伍在全宽范围内自由平移。

黄色队长标记用于过门与攻击预警判定；后方小队是兵力的视觉代表，最多绘制 28 名跟随者以控制画面密度，实际兵力没有 999 上限。兵力、攻击强度、齐射伤害和每秒火力独立显示，公式见 [数值文档](BALANCE.md)。

## 门：两道或三道、不等宽

每组门只有一次结算机会，以队长中心进入的区间为准；门之间有窄缝，擦过门缝没有效果。正向门以绿色加法和蓝色乘法区分，红色代表减法/除法。视觉上直接显示运算符和数值，不能只靠颜色判断。

第 1 波双门；后续门组有 60% 概率三门。双门分割位置可偏左或偏右；三门中央奖励更高但通行面积不同。负向门组合会要求选择损失较小的一边，也可通过门缝舍弃整组收益。

基础加法量 A = 6 + floor((楼层−1)×0.65)。候选组合是 [+A, ×1.18]、[+(A+4), ×1.28]、[−max(4,A−1), ÷1.2]、[+(A+1), ×1.12]，左右随机交换。三门中间为 ×1.36/1.40/1.44，随幕变化。首层第一门固定用第一组，便于起步。

先应用运算和门强化，再添加职业/遗物召唤，最后保护最少 1 人；正向门再给誓言回响护盾。乘除向下取整。法师、星界契约和王者战旗在负向门也会召唤。

## 战斗内容

| 对象     | 行为                           | 处理重点               |
| -------- | ------------------------------ | ---------------------- |
| 骸骨先锋 | 持续接近，漏掉会冲击队伍       | 保持瞄准，提前打掉     |
| 幽林弓手 | 锁定当前位置，红区预警后射击   | 在输出与躲预警间移动   |
| 黑甲盾卫 | 生命 ×1.45、护甲 22%           | 用武器、暴击、回响突破 |
| 精英斥候 | 精英房额外出现，形成双目标压力 | 技能与弹射更有价值     |
| 荆棘地带 | 越界时检查队长位置             | 提前移出范围           |
| 补给宝箱 | 必须在越界前击破               | +22 金币、+4 兵力      |
| 兵装秘匣 | 必须持续攻击击破               | 武器等级 +1，最高 10   |
| 关底统领 | 中央停留、不断发出预警         | 躲避时保持有效瞄准     |

宝库中的三只箱子全部提升武器。普通房第 3 波为补给，第 6 波为兵装。宝箱到期直接失去奖励；不能仅经过领取。击杀敌人 +4 金币，完成普通/宝库 +28、精英 +55、首领 +80，再加渡鸦钱币奖励。

### 第 1 幕：荆棘边境

废墟之中，古老的誓言尚未熄灭。 该幕 8 波，首领为 **荆棘守望者**。锁定玩家当前横向位置的重斧，教授离开预警区域。

### 第 2 幕：月蚀回廊

月光消逝的地方，回响仍在低语。 该幕 10 波，首领为 **蚀月巫妖**。三片区域中只有一片安全，要求提前选择位置。

### 第 3 幕：余烬王座

最后一道门后，灰烬正等待新王。 该幕 12 波，首领为 **灰烬之王**。同时追踪玩家与另一侧位置，反应窗口缩短。

每个首领在登场 22 秒后进入狂暴，提高伤害但不直接宣判失败。关底仍可击杀，没有强制时间失败。

## 地图与房间

每幕第 1 层为普通/精英/事件组合，第 2 层为普通/宝库/精英组合，第 3 层为营火/商店/事件组合，第 4 层固定首领。路线只连接下一层相同列或相邻列；首领节点汇合，下一幕重新展开。

- **普通战斗**：基础风险、三选一。
- **精英哨站**：敌人生命 ×1.24、额外斥候、更多金币；奖励第二个候选优先非普通遗物。
- **遗落宝库**：敌人生命 ×0.85、三只武器箱，也有守关者和三选一。
- **营火**：恢复最大生命 40% 或武器 +1，二选一，不额外给遗物。
- **渡鸦商店**：每种商品每房限购一次；离开后推进一层。
- **祭坛事件**：失去 18 生命换随机职业优先遗物（生命必须大于 18）；支付 35 金币招募 22 人；或获得 12 金币离开。三选一。

## 商店与武器

| 商品     | 价格 | 效果                 |
| -------- | ---- | -------------------- |
| 绯红药剂 | 35   | 恢复 40 生命         |
| 佣兵契约 | 45   | 招募 18 名队员       |
| 精工锻造 | 70   | 武器等级 +1          |
| 神秘遗物 | 85   | 获得一项随机职业强化 |

初始金币 40。武器等级每级提高基础伤害 10%，Lv1–2 普通、Lv3–5 稀有、Lv6–10 史诗；武器外观名称跨阶改变。骑士：卫士长剑 → 破晓圣刃 → 不灭誓约；游侠：灰木长弓 → 猎风战弓 → 蚀月猎弓；法师：秘火法杖 → 星火权杖 → 群星终焉。名称阶级不会额外暗中增加另一层倍率。

## 遗物与 build

全部 25 项遗物、叠层与公式见 [数值设计](BALANCE.md)。三位原创人物与六套流派见 [人物与流派](CHARACTERS.md)。奖励不重复、排除已满层遗物；第一候选优先本职业，精英/首领第二候选优先稀有或史诗，池耗尽则回退可用池。这是候选资格倾向，不是隐藏稀有度权重系统。

六个方向为：骑士誓盾锋刃/荆冠远征；游侠猎王穿心/月影连锁；法师秘火蚀骨/星契回响。后两类固定附伤体系需要直击成长支持，不能宣传纯反伤或纯灼烧必过。

## 美术和后续 3D

三职业完整立绘使用生成式图像，按中世纪装备、统一材质光照制作。界面以墨绿石材、深蓝灰阴影和黄铜强调色呈现，职业头像从同一立绘裁显，保证一致性。在线使用本地 WebP，无远程字体、图片或游戏 API 依赖。

本版是 Canvas 2D 俯视战斗，角色立绘具有 3D 渲染质感；不包含可编辑模型、骨骼或真正 3D 场景。未来可保持当前世界坐标和正交相机，替换为 glTF 单位、短循环行走/攻击动画、实时接触阴影、分幕石材地形。不要重新引入透视投影导致远近速度错觉。

## 存档、版本与已知边界

关卡间自动存当前浏览器；战斗刷新回到入房前存档，不能从战斗中间恢复。新开局清除旧远征；死亡清空本局，保留最远层数。存档格式升级为 v2，不读取旧 v1 队伍数值，旧版最高记录保留。不提供云同步、账号、多人或永久天赋。

当前是可试玩的完整十二层切片。怪物模型、攻击动画、更多房间事件及独立机制的新职业属于后续内容。实际大陆网络连通性和触屏手感需要试玩反馈；部署方案见 [部署说明](DEPLOYMENT.md)。
