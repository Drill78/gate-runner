# 灰烬之门 · 游戏设计 v0.6

本版是三幕、每幕五关的完整远征。本文记录内部设计；公开教程、商店说明和初始图鉴只说明常规玩法，特殊遭遇在实际遇见时揭示。准确参数见 [数值文档](BALANCE.md)，条目与价格见 [构筑目录](BUILD_CATALOG.md)。

## 定位与主循环

原创中世纪奇幻 Gate Runner 与遗物构筑爬塔结合：选择职业 → 选择相连节点 → 战斗或处理房间 → 升级、领取奖励 → 下一关。第 5、10、15 关是章节首领，最后首领击杀即胜利；死亡结束本局。职业始终可选，没有永久数值强化。

实时部分要求横移瞄准、读取预警和施放职业技能；长线选择包括路线风险、生命与金币分配、即时补给和遗物协同。面板兵力是一种火力倍率来源，并非生命值或独立发射器数量。兵力使用对数收益，玩家弹体可能射空，因此单纯招募不能替代输出与续航构筑。

## 五层深度路线

每幕使用同一非交叉拓扑，房间种类由种子分配。每个节点保存显式 next ID 列表，进入只允许这些连接；不再用“相邻列”作为暗含通行规则。

| 幕内深度 | 节点列     | 典型内容                           |
| -------- | ---------- | ---------------------------------- |
| 1        | 0、2、4    | 普通遭遇、事件或精英，三个起点任选 |
| 2        | 0、1、3、4 | 宝库、战斗、事件、商店，各支线不同 |
| 3        | 0、2、4    | 精英、战斗或宝库，部分路径汇合     |
| 4        | 1、3       | 营火和事件，权衡恢复、锻造与资源   |
| 5        | 2          | 章节首领，汇合后展开下一幕         |

普通节点后面有一至两个连接，分岔与汇合按列序排列，不出现连线交叉。商店只在可选分支出现，有合法路线能完全避开；选择道路意味着放弃本幕某些房间机会。每个实际地图房间完成后都推进一关，不提供额外、不计层数的战斗支线。

- 普通遭遇：基础波次与战后三选一。
- 精英哨站：更高生命、额外增援与金币；战后三选一必含史诗或传说。
- 遗落宝库：三只可击破的宝箱，小怪与箱子房间生命因子较低，仍需打完关底。
- 营火：恢复最大生命 40% 或武器等级 +1，不额外发遗物。
- 渡鸦商店：每件商品每店限购一次，库存固定；离开推进一关。
- 祭坛事件：消耗 18 生命换随机遗物、35 金币招募 22 人，或拿取 12 金币离开。

神秘物品不新建地图支线。内部状态可把现有精英节点标记为 enchanted，其一次性资格在进入时消费；房间依旧是原地图上的精英，也正常计入关数。公开入口和初始教程不解释神秘钥匙与该状态的关联。

## 操作、空间与反馈

键盘 A/D 或左右箭头连续移动；松开停止，同时按两边停止。鼠标点选、触屏拖动均设置横向目标，速度上限 12 世界单位/秒；键盘速度 2.2。横坐标范围 −0.9 至 +0.9，没有离散赛道，没有指针缓动拖尾，也不瞬移穿越整个场地。

空格或右侧按钮施放职业技能，P/Esc 暂停。可选“双击人物释放技能”默认关闭，独立保存浏览器偏好。移动与技能按钮不互相覆盖。人物世界纵坐标为 0.8，敌人线性前进，使用统一俯视投影；远近不改变实体大小或移动速度。

黄色队长中心参与过门和攻击判定；后方士兵只代表军团，不扩大碰撞范围。兵力数字贴近队伍并横向跟随；短奖励提示位于角色上方，不盖住兵力。非章节关底和章节首领的大血条、名称由页面顶部展示，实体附近保留可读碰撞轮廓。

首领突入特写、升级菜单和暂停会冻结战斗时间，锁定移动与技能，不消耗冷却或压力宽限。减少动态效果设置控制视觉粒子和装饰，不改变引擎数值。

## 实际飞行攻击与职业构筑

普通攻击沿固定方向发射真实弹体，不锁定目标；射偏后继续前飞，普通命中即消失。穿透按命中顺序衰减，副弹和追猎碎片沿各自角度前进。预览阶段的实体还不能被伤害。横向瞄准、弹速与前排阻挡均会影响实际输出。

骑士用护甲、护盾与盾锋相映形成续航和伤害协同；游侠依靠攻速、暴击与多弹处理目标；法师以秘火、回响、召唤和弹幕强化成长。主动技分别为护盾与限时增伤、全场箭雨、全场秘火与召唤。

当前共有 33 项遗物，包含 15 项通用和每职业 6 项。双翼符印、不灭圣约、月神之弦与群星之核为传说。职业遗物累计三层触发共鸣，重复层数计入，通用遗物不计入。固定反伤或灼烧需要直击成长支持，不承诺只靠固定附伤通关。

## 经验与奖励决策

角色等级上限 15，每级攻击因子增加 2%、最大生命与当前生命各 +2，同时提供一次遗物选择，最多 14 次。升级需要经验 30 + 14×(L−1) + 6×max(0,L−5)²，满级累计 3404 XP；前期升级节奏保持，后期需求提高。

升级菜单仅从本职业和常规通用未满层遗物取候选，不发即时补给或钥匙。选择后立即生效，连升多级依次处理，也可跳过。可用池不足三项时展示实际剩余数量，空池自动处理，不能让战斗永久暂停。

战后奖励仍只取一项。第一项优先本职业；存在有效补给时，第三项有 45% 概率变成恢复 40、招募 50 或武器 +1。精英战后三选一额外保证至少一项史诗或传说，适用于所有精英房间；有战后奖励的章节首领也采用相同保底。保底检查发生在补给替换之后。

仍有未满层高稀有遗物时，保底来自该池；所有适用高稀有遗物满层后，以史诗军资（120 金币、恢复 50）兑现。精英候选彻底不足时再补不屈精粹或王庭援军，保证三项互不重复且可领取。备用品是立即生效的史诗消耗品，不占遗物层数，不加入普通随机池、升级或商店。

最后章节击杀直接胜利，没有多余的战后选择；赢帧产生的升级仍需先处理。重复点击同一已消费菜单不会重复领取。

## 商店与武器

初始金币 40。注册商品 18 种，每店从当前职业适用的常规商品中固定随机取五件，再陈列满足购买条件的神秘钥匙，固定价格 500 金币。种子、关数与节点决定库存；查看、筛选、购买、恢复存档都不重抽。非库存、满层、满血、满武器或金币不足时不能扣费。

武器上限 10，每级基础攻击 +10%；名称在 Lv3、Lv6 跨阶变化，名称阶级本身不再暗加一层倍率。各店限购记录独立；定向商品补齐构筑缺口，补给让玩家在短期存活与长期成长之间取舍。

公开目录中的神秘钥匙仅展示其名称、价格和神秘描述；不列购买后的步骤、门类型、触发地点或奖励收益。特殊内容由战斗现场逐步揭示。

## 关底与章节首领

非章节关底轮换荒野刽子手、黑甲统领、咒刃骑士、石誓巨像、蛛巢主母：分别围绕散斧追击、正面盾牌、双重锁定斩痕、留有缝隙的裂地震击、毒弹与蛛网组织战斗。其攻击预警与实体弹幕可通过走位应对。

第一幕首领轮换荆棘守望者与岚翼古龙；第二幕轮换蚀月巫妖与命运先知；第三幕最终首领为灰烬之王。前两幕提供不同弹道与落点机制，最终战随生命阶段切换技能强度，要求持续瞄准、读预警、处理安全区和打断机会。完整参数以当前引擎和数值文档为准。

章节压力是交战一段时间后周期触发的独立 DPS 检测，只伤护盾与生命、不损兵，不可用走位规避；持续压力要求输出和续航同时成立。普通精英不带章节压力。玩家在截止帧击杀首领会阻止当帧压力，特写和升级不会偷走宽限时间。

## 长线难度与验证

15 关采用普通小怪成长 1.27、全部关底成长 1.26，普通小怪首关基础生命仍为 110，第二关起额外 +15%。非章节普通关底基础 1290、精英 1650；章节基础 3400，再乘幕倍率与最终首领独立参数。具体公式与逐关参考表见数值文档。

路线、精英保底、较慢的后期升级和最终战同时改变了成长曲线。此前较少关数、不同最终技能组下的模拟结果不能直接作为当前胜率。发布烟测应明确源码 SHA、每职业样本数、种子、公开信息控制策略、升级与奖励记录、失败关数和超时数量。

模拟器通过真实 movePlayer 速度限制移动，读取已出现敌人、预警和绿色安全区；真实商店 API 负责库存、限购与扣费。精准命中、快速反应和窄门过法与真人手机操作有明显差异，少量烟测只能说明流程是否跑通，不能承诺流派通关率。

## 存档、图鉴与边界

远征采用 Run.version=4，关卡间保存于本地浏览器；不恢复战斗中间帧。存档记录显式 next 路线、待领奖励、已选升级、商品限购、encountersDefeated 和 secretDiscovered。怪物记录与收藏展示使用实际遭遇和击败记录；秘密发现必须等战斗真正展示对应内容，不能在购买商品时提前解锁。

旧 v2/v3 存档回到旧进度对应幕的起点：构筑、金币、兵力、生命、经验及待领奖励保留，只重建路径与房间入口，并用日志明确提示。旧已领升级保留至最多 14 次；如果超过新曲线对应等级，等等级追上后才继续发卡。恢复会拒绝不相连的路径、非法计数或不支持的状态，不静默修成可跳关路线。

声音、教程已读、双击技能偏好和收藏记录独立于远征，没有永久攻击天赋、账号或云同步。艺术使用本地 WebP 与 Canvas 2D，具有立体绘制质感但并非可编辑 3D 场景。后续若替换为模型和骨骼动画，应保留世界坐标与等比例投影，避免远近速度错觉。
