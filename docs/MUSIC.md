## 播放与制作文件

游戏播放 public/audio/*.mp3。七首新曲 URL 带 ?v=1.0，避免旧曲缓存。浏览器首次点击或按键解锁声音；静音、暂停和后台暂停播放，最终战恢复时不会重放前奏。曲目按场景加载，解码缓存最多三首，切曲使用淡入淡出。

主界面音乐覆盖开门和选职业；地图音乐也用于选奖与营火；胜败结算回到主界面主题。战斗中的升级选择和菜单继续暂停战斗音乐。禁忌场景优先使用保留曲。

本地 artifacts/music-v1/ 中的 _-master.wav 是混音、响度处理后的无压缩母带，供 MP3 编码；_-decoded.wav 是最终 MP3 回读的 WAV，供检查实际编码听感。解码不能恢复 MP3 丢失的细节；禁忌曲只有回读文件，本轮不生成其母带。

新制作入口是 scripts/generate-score-v1.py，复用 scripts/generate-music.py 中的原创乐器模型，并增加管风琴、木管、独立曲式和含前奏的循环混音。所有重混和音频文件在开发时生成，游戏运行无需 Python。最终战的尾音写入主体循环起点，不流回前奏；前奏只在进入该曲时播放一次。

```powershell
python scripts/generate-score-v1.py --ffmpeg "C:/path/to/ffmpeg.exe" --work-dir artifacts/music-v1
# 只回读导出文件，不重写 MP3
python scripts/generate-score-v1.py --ffmpeg "C:/path/to/ffmpeg.exe" --work-dir artifacts/music-v1 --validate-only
```

依赖 Python、NumPy、SciPy 与支持 libmp3lame 的 FFmpeg。本轮 FFmpeg 7.1 来自独立工具目录，不是游戏依赖。新脚本无论选择哪些曲目都只校验禁忌文件，不重生成它。历史 v0.7 制作报告保留在 docs/data/music-v07-report.json。
