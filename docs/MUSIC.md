# 灰烬之门 · 原创配乐 v0.7

四首均为原创、无歌词的程序化器乐合成。没有第三方音乐片段、外部采样或真人演唱；游戏加载已生成MP3，无需运行制作脚本。

前三首共享原创D小调主题，**统一112 BPM**。宏大感来自编配、和声、音域与节奏层次：普通战保留旋律与吉他推进；章节战加入宽阔铜管主题、弦乐回答与定音鼓；最终战以低弦、弦乐断奏、铜管、无字合唱、定音鼓和重吉他构成交响金属。段落有半拍鼓组与全合奏的变化，不再用加速作为主要区别。

《门后的低语》保留原80 BPM、半音张力、钟声与稀疏战鼓。其文件SHA256与v0.6发布记录完全相同，未重做。

## 制作与验证

吉他采用多泛音琴弦、双轨与过载箱体滤波；弦乐采用失谐弓弦声部和柔和起音；铜管有逐渐展开的谐波；定音鼓、鼓组、低音与合唱垫均为合成音色。各乐器分组混音，使用房间、长残响与交叉延迟。音色属于程序合成，未描述为真人乐团录音。

音符释放和混响按环形写入循环开头，周期卷积保留尾音；整曲不淡出。验证覆盖40–90秒、声道与采样率、解码长度、削波、峰值、综合响度、接缝及总大小。接缝附近短窗能量会随下拍鼓点改变，波形检查不能代替主观听感。完整测量见 [JSON](data/music-v07-report.json)。

## 重现

依赖Python、NumPy、SciPy和支持libmp3lame的FFmpeg。本次编码器为FFmpeg7.1，来自独立工具目录的imageio-ffmpeg0.6.0，不是游戏依赖。

```powershell
# 只重做前三首，保留禁忌音乐
python scripts/generate-music.py --ffmpeg "C:/path/to/ffmpeg.exe" --only normal boss final --work-dir artifacts/music-v07
# 回读验证，不改变任何MP3
python scripts/generate-music.py --ffmpeg "C:/path/to/ffmpeg.exe" --validate-only --work-dir artifacts/music-v07
```

生成脚本使用固定随机种子，母带和报告写入工作目录，只有MP3进入public/audio。前三首播放器URL增加v0.7查询标识，旧浏览器缓存不会继续复用v0.6曲目。播放器的暂停、后台、静音和异步切曲竞态由单元测试覆盖；本轮未进行浏览器听测。
