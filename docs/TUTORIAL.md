# 图文教程 v0.6

教程由 `components/game-tutorial.tsx` 的 `GameTutorial` 导出，自动引入同目录 CSS。接口只有 `onComplete: () => void`，末页「开始冒险」按钮调用它；内部仅维护当前页，不读写存档、不直接暂停游戏。

```tsx
import { GameTutorial } from '@/components/game-tutorial';

<GameTutorial onComplete={finishTutorial} />;
```

`app/page.tsx` 将组件放入已有 Dialog，并提供 DialogTitle、首次启程检测、完成状态持久化、暂停逻辑与重看入口。入口圣门和职业选择阶段不自动盖上教程；首次离开开局页进入远征后，未完成教程的浏览器自动显示。每次重新挂载从第一页开始；组件没有内部关闭按钮，关闭与继续冒险后的游戏状态由调用方决定。

## 四页内容

| 页码 | 主题           | 图示和内容                                                                                                                                                                                                     |
| ---- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 移动与射击     | 队伍全宽横移，拖动或按住 A/D、方向键；自动向前发射实际飞行弹体，横移调整弹道，打空继续飞过敌人；右侧技能按钮或空格释放技能。暂停菜单可开启双击人物释放技能，默认关闭，偏好保存在当前浏览器。                   |
| 2    | 选门与兵力     | 不等宽加法/乘法门，也可能出现三门，队长中心每组结算一次。人数越多火力越高，与生命和攻击强度不同；同时考虑门的收益、位置和后续射击。示例：24 人选 +10 得 34 人，选 ×1.28 得 30 人。                             |
| 3    | 奖励与构筑     | 击杀金币与经验；升级时自动暂停，三选一职业或弹幕强化，选好继续战斗。兵装秘匣提升武器，补给箱给金币和兵力；战后奖励加入治疗、招募与武器升级。图中三张为骑士护盾相关候选示意，未混用跨职业专属遗物。             |
| 4    | 首领与章节压力 | 关底精英和章节 Boss 的常规攻击都能躲避；观察顶部大血条，移出红区、穿过弹隙。灰烬之王吟唱可集火或技能打断，也可进入图示的绿色安全区。只有章节周期压力不可躲避，伤害逐次增加，检验输出和续航；暂停菜单可以重看。 |

教程尽量避免写死波次、遗物总数、伤害与冷却，便于后续数值调整。选门示例用于解释运算；实际加减量随兵力缩放。飞行弹体和右侧技能按钮按当前机制说明，教程只介绍常规玩法，特殊遭遇由战斗现场提示。

## 入口与远征规则补充

以下说明对应入口、地图、奖励和收藏界面，四页组件仍以基础操作为主，不额外增加分页。

- **从圣门启程：**点击「开启圣门」，待门扉打开后选择骑士、游侠或法师，再确认启程。有可用存档时可在入口继续上次远征；设置入口提供操作偏好与图鉴成就。
- **三幕各五关：**远征共十五关，地图上的连线决定下一步可达地点。沿已连接的普通战斗、精英、宝库、营火、商店和事件前进，第 5/10/15 关迎战章节首领。位置相邻不代表路线相连。
- **五种精英、五种章节首领：**普通与精英关底会在五种强敌间轮换；第一幕终点为荆棘守望者或岚翼古龙，第二幕为蚀月巫妖或命运先知，最后是灰烬之王。每位敌人有独立立绘和应对提示，熟悉一种敌人后仍要观察下一位的预警。
- **精英奖励保底：**精英与章节首领战后，三项候选中至少有一项史诗或传说奖励。高级遗物拿满时仍有史诗补给可选；选择一项领取，不会一次获得整组候选。普通战后也可能获得治疗、招募或武器升级。
- **收藏跨远征保留：**设置中的「图鉴与成就」记录已击败强敌、招式说明、击败次数和职业通关。首次击败后解锁相应档案，新开远征不会清空；收藏不增加局外属性。记录只保存在当前浏览器，未发现的隐藏成就保持问号，不提前公布条件。
- **灰烬之王的三阶段：**大血条在 70% 和 35% 处标记阶段变化。碎日王冠火环、陨火葬城和交叉焚风都有可躲空隙；敕令可集火打断，也可进入绿色安全区。第三阶段施法更快、绿区更窄，仍以实际预警为准。章节周期压力是独立机制，拖延过久会持续增强。

普通教程和未解锁收藏只说明常规玩法，不透露隐藏物品的用途、特殊门的开启条件或秘密奖励。

## 交互与适配

- 四页提供上一页、下一页、页码和进度圆点；第一页禁用上一页，末页按钮为「开始冒险」。
- 翻页时内容滚回顶部，标题与摘要通过礼貌实时区域供读屏工具播报；图示有文字替代说明。
- 所有图示为本地 SVG/CSS，没有图片生成或外部资源请求，没有独立轮播计时。
- 组件限高为 `min(740px, 100dvh - 120px)`；内容区域独立滚动，标题栏和翻页按钮保持可用。320px 窄屏压缩横向间距，矮屏缩小图示。
- 按钮高度至少 44px，保留键盘焦点轮廓。减少动态效果偏好会关闭翻页淡入与按钮过渡。
- CSS 限定在 `.game-tutorial` 下，不修改现有 Dialog、页面、存储或全局样式。
- 完成末页或关闭教程均记忆已查看状态；即使本地存储暂时不可用，同次页面会话也不会立刻反复弹出。暂停菜单与角色的冒险手册可手动重看。
- 查看教程、设置、收藏或角色详情时，调用方阻止战斗推进与技能输入。从暂停菜单进入教程后，关闭教程仍回到暂停状态，需要按「继续战斗」恢复。
- 精英与 Boss 的约 3 秒突入也暂停战斗，可点击、空格或回车跳过；跳过不会同时释放技能，暂停或切后台期间不接受跳过。减少动态效果偏好直接展示完整立绘。

远征使用格式 v4 存档，收藏独立保存。旧 v2/v3 存档可迁移资源、经验与已选强化，但旧地图无法逐节点对应新连线，因此回到对应幕起点重新选路，待领取奖励保留；缺少经验的 v2 档从零经验起步。

升级选卡、首次启程和暂停入口由调用方接线；组件本身只负责图文分页。本说明依据源码更新，不把静态检查等同于浏览器或触屏验证。
