# 图文教程

教程由 `components/game-tutorial.tsx` 的 `GameTutorial` 导出，自动引入同目录 CSS。接口只有 `onComplete: () => void`，末页「开始冒险」按钮调用它；内部仅维护当前页，不读写存档、不直接暂停游戏。

```tsx
import { GameTutorial } from '@/components/game-tutorial';

<GameTutorial onComplete={finishTutorial} />;
```

由调用方放入已有 Dialog，并提供 DialogTitle、首次打开检测、完成状态持久化、暂停逻辑与重看入口。每次重新挂载从第一页开始；组件没有内部关闭按钮，关闭与继续冒险后的游戏状态由调用方决定。

## 四页内容

| 页码 | 主题           | 图示和内容                                                                                                                                                                                                                                                     |
| ---- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 移动与射击     | 队伍全宽横移，拖动或按住 A/D、方向键；自动向前发射实际飞行弹体，横移调整弹道，打空继续飞过敌人；右侧技能按钮或空格释放技能。没有锁定连线或双击技能。                                                                                                           |
| 2    | 选门与兵力     | 不等宽加法/乘法门，也可能出现三门，队长中心每组结算一次。人数越多火力越高，与生命和攻击强度不同。先取得禁术钥印，下一次精英才开启本局唯一试炼：先过五道全宽必经红门，再争夺极窄平方 x² 门，旁边可选 √x 或加法。示例：24 人选 +10 得 34 人，选 ×1.28 得 30 人。 |
| 3    | 奖励与构筑     | 击杀金币、经验与局内升级；兵装秘匣提升武器，补给箱给金币和兵力；战后三选一围绕职业搭配。图中三张为骑士护盾相关候选示意，未混用跨职业专属遗物。                                                                                                                 |
| 4    | 首领与章节压力 | 关底、精英和章节 Boss 的顶部大血条；红区与弹隙走位；灰烬之王的吟唱可集火或技能打断。只有章节 Boss 有交战后的周期全屏压力，伤害逐次增加，检验输出和续航；暂停菜单可以重看。                                                                                     |

教程尽量避免写死波次、遗物总数、伤害与冷却，便于后续数值调整。选门示例用于解释运算；实际加减量随兵力缩放。禁术试炼需要钥印且本局只开启一次，并非每个精英都能选平方门。飞行弹体和右侧技能按钮按本次更新的机制说明，不介绍旧版自动锁定命中。

## 交互与适配

- 四页提供上一页、下一页、页码和进度圆点；第一页禁用上一页，末页按钮为「开始冒险」。
- 翻页时内容滚回顶部，标题与摘要通过礼貌实时区域供读屏工具播报；图示有文字替代说明。
- 所有图示为本地 SVG/CSS，没有图片生成或外部资源请求，没有独立轮播计时。
- 组件限高为 `min(740px, 100dvh - 120px)`；内容区域独立滚动，标题栏和翻页按钮保持可用。320px 窄屏压缩横向间距，矮屏缩小图示。
- 按钮高度至少 44px，保留键盘焦点轮廓。减少动态效果偏好会关闭翻页淡入与按钮过渡。
- CSS 限定在 `.game-tutorial` 下，不修改现有 Dialog、页面、存储或全局样式。

本轮采用代码、类型和静态检查；未进行浏览器截图或点击验证。首次启动与暂停入口由调用方接线后统一验证。
