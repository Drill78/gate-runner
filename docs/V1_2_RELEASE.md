# 1.2.0 · 登神远征

2026-09-08。六轮长夜之后，远征有了完整的终点。第100关正式通关并记录成绩，第101关为正向奖励、祝福与制作人署名，结束后不再无限刷关。

## 本版内容

- 困难与指定无尽战中的灰烬之王拥有第二条命、全新复燃立绘和技能组。普通模式保持一条命。首领各幕突入完整3秒，灰烬之王各命4秒，均不可跳过；演出冻结战斗。
- 黯化形成黑影伤害区；血月攻击更快、命中玩家后持续回血；金身替代空冠，具有可击破护盾与短暂无敌；合葬混合技能。异化有对应颜色、恢复与护盾反馈。
- 前90关分为六轮，每轮三层、每层五关。第三、第六轮陡升，其余轮较平缓；包含双王、三王、首领带精英及多幕连战。第90关为两组双首领后接三位异化灰烬之王。
- 第91—98关引入天使化：白翼、减伤与恢复；首次击倒后复生并进入10秒无敌狂暴，随后时停碎翼，解除神佑。第99关为两条命的登神灰烬之王，第100关为横跨战场的主神。
- 三套新首领技能共17招。主神降低攻击压力，以72秒共享承伤预算保留完整演出；弹幕、DOT、主动与援击共用预算。兵力再高也不能省略关键机制。
- 章节交接恢复最大生命的50%，加入分章叙事。新战绩页展示职业、构筑、生命与兵力变化曲线。曲线使用本局实际采样，旧档缺少的数据不会补造。
- 第15、45、75关各获得一枚归魂币，一局最多获得三枚。阵亡可消耗一枚满血重启本场，或承认本次失败；已花掉的币会即时保存。通过45、90关后分别解锁46、91关的固定誓装续战。
- 公共史册区分完整远征、46关续战和91关续战。百关正式结算授予姓名星印、金色界面及隐藏成就「登神」；101关不会覆盖百关的称号或成绩。离线结算进入待上传队列。
- 七张新增AI美术及一首135秒登神主题音乐；原八首MP3保持不变。新增素材与生成记录见[媒体说明](V1_2_MEDIA.md)。立绘和战斗图仍为2D素材，完整3D重构保持独立项目。

用户设计逐条保存在[设计原案](V1_2_ASCENSION_DESIGN.md)。精确阵容与预设见 `lib/endless.ts`、`lib/presets.ts`，数值册和75项奖励见[数值调试册](BALANCE_REFERENCE.md)。

旧版无尽成绩继续保留在个人履历，旧深度不会直接点亮新版成就或续战篝火。旧远征保留构筑，以新的私人续接记录继续；原已过45／90关的存档分别回到新版第45／90关重新接受检验，实际击败后才解锁对应篝火。普通与困难存档维持兼容。

完整长阶测试建议至少亲自观察：白翼期间的10秒躲避是否读得清、三王同时登场时血条与预警是否拥挤、主神72秒演出是否过长、手机拖动时能否顺畅选择安全路线。这些主观体验需要真人试玩。

## 验证口径

197项自动测试通过，覆盖战斗机制、存档、史册、迁移和离线称号。实际引擎另验证36组：6组困难、12组完整无尽、6组续战预设、9组关键首领均达成目标；3组站桩对照在92—93关失败。22组服务端渲染结构检查通过。具体数据和局限见[难度报告](V1_2_BALANCE_AUDIT.md)。自动驾驶结果不等于真人胜率，没有据此声称真机交互或主观听测已完成。
