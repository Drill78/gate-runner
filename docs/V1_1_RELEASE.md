# 1.1 · 长夜无尽与灰烬史册

## 游玩

首次通关后，在启程界面选择「无尽 · 长夜远征」。前十五层后继续探索，地图每十五层轮换。20 层起逐一揭示双誓守陵、不息追猎、王影相噬、血月畸变、合葬圣体、无冠王庭等遭遇；后期根据远征种子轮换。最多三首领同场，多段追猎包含段间恢复与清场。黯化留下黑影裂隙，血月加快发招，空冠获得间歇正面护佑，合葬交替使用两套首领术式。

每五层首领后获得长夜契约：薪火、军势、圣血，以及中后期的焚印重铸、失冠者盟誓和深门残章。首领盟友每八秒发动随自身输出成长的援击；20 层后可签订第一份盟誓，40 层后可有两位同行。焚印将普通符文转化为本次远征内保留的伤害倍率，提供三层淬火钢刃及三个职业符文作为重建基础。契约、武器、生命与盟友保留，收益不带入下一局普通／困难。

首把禁忌秘钥仍为 666。实际穿越平方秘门后，深门残章允许渡鸦出售下一重秘钥，价格依次为 6666、66666 等。无尽武器上限提高至 10000，生命上限可继续通过契约增长。回到地图时可「归还火种」，结算并记录当前深度。

## 排行榜

启程前填写旅人之名，设置中可修改。结束远征后填写称号；名字与本次称号出现在史册中。普通、困难只收录胜利，无尽完成五层起收录陨落或归途。每种排序只展示每位旅人的最佳一局，支持职业筛选及分页。排序支持净交战用时、最高兵力、累积金币；无尽以最深关数为默认。

个人履历保存实际战绩、职业、种子、符文、武器、生命上限、击杀、宝箱、门、盟友、重铸、禁门深度和输出。暂停、读卡和菜单时间不计入交战用时。公共数据存于 D1；本机保存随机旅人凭据和待发送结算。清除站点数据会失去当前旅人印记，名字相同不会合并身份。离线启程或足迹不完整的记录只进入个人履历。

这是客户端荣誉榜，有字段校验、归属验证、服务器开局时间、逐关足迹、幂等结算和写入频率限制；不承诺抵御修改游戏代码的作弊。不填充虚构公共成绩。

## 验证

143 项自动测试通过，包含地图百层存档、分段连战、双王、融合、重铸、钥匙层级以及真实 SQLite 上的公共排序、身份隔离、幂等结算和非法输入。TypeScript 与 lint 通过，静态前端和 Sites Worker 构建通过。

本轮 36 局真实引擎模拟：普通 12/12 通关，困难 10/12 通关，无尽 12/12 到达 75 层。额外六局深层样本中五局到达 200 层，一局游侠在 149 层因首领压力陨落。另有八种明确标为预设构筑的机制探针，全部完成对应首领遭遇，含三段连战。自动驾驶每 150 毫秒决策，优先连贯构筑，结果用于发现数值断层，不能等同真人胜率。没有进行浏览器交互测试或真机试玩。

详细曲线见 [V1_1_DESIGN.md](V1_1_DESIGN.md)。本地报告：`artifacts/endless-balance-v11.json`、`artifacts/endless-deep-v11.json`。原有八首音乐全部保留。

## 运维

Vercel 继续提供游戏静态文件，通过 `/api/chronicle/:path*` 转发到本项目的 Sites Worker。Sites 绑定 `DB`，迁移位于 `drizzle/`，源定义位于 `db/schema.ts`；迁移只在部署时运行，不在请求中建表。数据库无用户口令或邮箱，仅存随机凭据的 SHA-256 摘要。

发布顺序：提交并推送源代码；`npm run build:sites` 后用 Sites 官方打包脚本保存、发布同一提交；确认匿名 `/api/chronicle/health` 与空榜／真实榜响应；再使用固定 Git SHA 的 Vercel 构建入口发布静态游戏。Vercel 尚未接通 Git 自动部署。回滚游戏前须保留数据库与迁移历史，不删除已产生的玩家战绩。
