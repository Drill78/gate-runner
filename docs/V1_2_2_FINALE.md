# 1.2.2 · 长阶配乐与最后的祝福

2026-09-08。此文保存本轮用户设计及实现约定。

## 用户设计

- 第 91–98 关空灵、神圣；第 99 关紧张刺激；第 100 关先空灵前奏，再进入紧张战斗，参考日式 RPG 的配器与情绪层次。
- 第 101 关作为轻松、搞怪的谢幕。只有不断出现的假平方门；通过第一道门，人物头顶显示中文 **「无限大」**，对应游戏王梗，不使用 ∞ 符号。
- 无限大仅用于显示，不进行平方运算、不改变兵力。宝箱击破后，在屏幕随机位置出现用户提供的鼓掌 GIF，随后淡出。
- 祝福文字只有「恭喜」「谢谢」。播放用户提供的完整录音，播完才出现制作者署名与结尾。

## 实现

两套原创音乐主题及主神专属前奏版已接入：91–98「圣阶浮光」、99「裂冠之战」、100「曙光裁决」。对应 136 / 120 / 144 秒；循环点 8 / 0 / 24 秒，前奏只播放一次。配器、来源许可、母带位置和客观音频指标见 [配乐制作说明](JRPG_FINALE_SCORE.md)。此前九首音乐原样保留，包括禁忌之门。

101 使用用户提供的 `V.A. - Good, or Don't Be (1).mp3` 原始字节，公共文件为 `public/audio/congratulations.mp3`。录音不属于本轮原创作曲。编码时长 83.52 秒，按无间隙元数据解码为约 83.4667 秒。SHA-256：`941700428e75cae46e4ae3e04eee2468c9fa3a052d4048966956a1bed7b9bf6f`。

GIF 原样复制到 `public/art/congratulations-evangelion.gif`，SHA-256：`9ca3f7799b1ca25e6c2047a865b90dc14cde48874272c22a1e6de4a68f85afbe`。用户在项目根目录提供的原件保留。

平方门每 1.35 秒出现。中心宝箱全程可击破，侧面宝箱从稀疏到密集；全曲 120 箱，站中央也可持续击破 60 箱。只有实际子弹击破触发 GIF，漏过不会自动补发。GIF 随机在上半场与中部出现，缓缓上浮与淡出，避免压住角色；同时维护有限事件列表。后半段宝箱更密集。最后两秒不再生成来不及抵达的新宝箱。

第一道平方门只设置 `epilogueInfinity`，绘制「无限大」。不运行门运算，不触发符文、不增长金币/经验/血量/巅峰军势、不修改百关旅程；101 技能不施放，不会让法师技能乘算兵力。百关统计与公共史册仍以真实远征成绩为准，101 不重复提交通关。

尾声以 Web Audio 的实际播放位置驱动游戏进度，只有本次录音自然结束才进入结尾。暂停或切后台冻结播放；静音只降低录音音量，仍能正常走完整段。每次演练拥有独立播放身份，旧异步下载与结束事件不会串入新一轮。网络/解码失败，或音频连续 12 秒无法前进时，使用等时静默流程避免卡死；静默回退后不接入迟到的音乐。完整录音和暂停逻辑由专项测试覆盖。

尾声隐藏资源、技能和战斗倒计时，只保留暂停按钮；音乐播放期间不混入战斗音效。结尾为「恭喜」「谢谢」与 **绿色咸咸圈&GPT-6 Astra**，可返回启程之地；开发者测试保留退出和返回演武场。第 100 关原有金色统计画面仍然保留。

同时修复指定主神演练被误当成独立首领测试、绕过百关结算的路径：99/100 专用预设现在可正常连续进入结算和 101。演练仍不能写入正式存档、成就或排行榜。

## 验证范围

专项测试覆盖三职业真实弹道击破、假平方不改数据、音乐时钟/暂停/静音/异步隔离、中文渲染、百关→101→结尾及开发者路径。236 项自动测试、TypeScript、lint 与静态构建通过。浏览器已验证实际 GIF 动画、中文无限大、暂停后恢复以及制作者结尾；390×640 手机尺寸的第二次静音演练亦完成谢幕，73.1 秒时仍在祝福场景，102.4 秒检查时已到结尾；未发现 error 级浏览器消息。发布资源检查随上线归档。本轮没有改动 1–100 的战斗数值，不将程序测试称作真人完整通关。
