# 飞行弹幕构筑与渡鸦商店 v0.6

> 当前版本为v0.7；新增数值与机制以 [v0.7改动](V0_7_UPDATE.md) 为准。以下保留v0.6详细基线，冲突处由新版说明覆盖。

当前远征共 15 关，每幕 5 关；角色上限 15 级。共有 33 项遗物：15 项通用、每职业 6 项。升级可以选择强化，精英战后三选一必含史诗或传说，战后也可能获得即时补给；商店只在可选路线分支出现，每家固定抽取货品。职业身份和构筑详见 [人物与流派](CHARACTERS.md)。本页记录公开条目与常规玩法。

## 弹幕怎样命中

普通射击自动向前发射实际弹体，横移决定发射位置，弹体不追踪或锁定敌人。射偏后继续前飞，直到离开场地；穿透弹可以继续命中后方目标。主动职业技能保留其护盾或全场打击效果，与普通弹体分开结算。

主弹伤害仍由攻击强度与兵力倍率相乘得到。面板「理论主弹 DPS」只估算主弹、攻速与平均暴击收益；实际输出取决于命中率，还可能受到副弹、穿透、爆裂、低血增伤、回响、碎片、灼烧和技能影响。多枚弹体不代表必定全部命中同一个首领。

兵力倍率始终使用 `1 + log2(1 + 兵力 / 12)`。人数越多，火力越高；没有高兵力阶段的额外削减。实际兵力保留到安全整数上限。

## 七项弹幕词条

以下表格由当前遗物数据生成，除另有说明外，百分比按层数线性累加。

| ID       | 名称     | 稀有度 | 最大层数 | 效果                                                |
| -------- | -------- | ------ | -------- | --------------------------------------------------- |
| split    | 双翼符印 | 传说   | 2        | 每层增加左右一对斜向副弹，每枚造成主弹 50% 伤害。   |
| pierce   | 贯阵尖锥 | 稀有   | 3        | 每层多穿透 1 个目标，每次穿透后保留 75% 伤害。      |
| velocity | 疾风导环 | 普通   | 2        | 弹体飞行速度 +25%。                                 |
| blast    | 炼金火芯 | 稀有   | 3        | 命中时，对周围其他目标造成弹体伤害 30% 的范围伤害。 |
| heavy    | 铅铸重弹 | 普通   | 2        | 主弹伤害 +25%，攻击速度 −10%。                      |
| focus    | 聚能刻印 | 普通   | 2        | 弹体半径 +30%，伤害 +10%。                          |
| execute  | 终猎契印 | 稀有   | 2        | 对生命低于 30% 的目标，额外伤害 +20%。              |

- **散射**：每层增加一对副弹，最多额外 4 枚；加上主弹，常规齐射最多 5 枚。副弹以斜角前飞，不自动寻找目标。
- **穿透**：最多额外穿过 3 个目标；每次穿透后伤害乘 0.75，按经过目标的次序递减。穿透不是无视护甲。
- **重弹与聚能**：共同组成一个伤害加成项 `1 + 0.25×heavy层数 + 0.10×focus层数`；重弹另使攻速乘 `1 − 0.10×heavy层数`。两者不会各自独立相乘。
- **终猎契印**：只对当前生命比例低于 30% 的目标增加伤害，不是直接处决，也不是额外暴击判定。

### 五个搭配方向

| 方向     | 主要组合                                     | 操作与弱点                                                                         |
| -------- | -------------------------------------------- | ---------------------------------------------------------------------------------- |
| 穿透爆裂 | 贯阵尖锥 + 炼金火芯 + 疾风导环               | 尽量把前后目标放在弹道上，让多次命中覆盖附近敌人；空旷场地和孤立目标会降低范围收益 |
| 多重暴击 | 双翼符印 + 鹰隼之眼 + 追猎回响，可补致命瞄准 | 游侠以散射覆盖和暴击碎片处理多目标；碎片不会转弯追敌，不能按理论弹数承诺单体倍率   |
| 重弹收割 | 铅铸重弹 + 终猎契印 + 聚能刻印               | 以更大的主弹和单发伤害收尾；攻速下降会减少开火机会，仍需稳定瞄准                   |
| 骑士破阵 | 盾锋相映 + 誓言回响 + 贯阵尖锥，可补铅铸重弹 | 用护盾维持伤害，向前打穿阵列；护盾耗尽会同时削弱生存与输出                         |
| 法师纵火 | 法术回响 + 魔力奔涌 + 炼金火芯，可补疾风导环 | 回响和爆裂形成持续输出，弹速减少目标移动期间的落空；固定灼烧仍需直击成长支撑       |

这些是可形成协同的选择方向，不是预设职业套装、必出配方或通关保证。通用弹幕遗物不计入三层职业共鸣；选取它们时仍需给职业核心留出强化机会。

### 交易规则

`shopInventory(run)` 决定可见库存；`shopItemAvailability(run, id)` 返回可购状态和原因，供界面显示；`canBuyShopItem(run, id)` 与 `shopBuy(run, id)` 使用同一校验规则。

- 不在商店、商品不存在、金币不足或本店已购买时，不改变原始状态。
- 满血不能购买治疗；武器 10 级不能锻造；兵力到达安全整数上限不能招募。
- 遗物满层或职业不适用时不收费；随机遗物无候选时不收费。
- 最大生命提升来自定向购买橡木之心，同时按该遗物恢复生命；即使原先满血，也能正常获得上限提升。
- 治疗最多恢复至当前生命上限，招募最多至安全整数上限。已有但未满层的遗物可在后续商店继续购买。
- 购买成功后才保存本店购买记录，原始 Run 对象保持不变，便于页面和存档原子更新。

当前存档格式为 v4，记录显式路线、已选升级、商品限购及待领补给。旧 v2/v3 存档回到对应幕起点，保留构筑、金币、经验和待领奖励，并显示迁移日志；细节见内部数值文档。

## 升级选择与战后补给

每次升级保留基础攻击成长 +2%、最大生命与当前生命各 +2，并额外提供一次强化三选一。战斗自动暂停，选定后继续；连升多级依次选择。候选来自未满层的本职业与常规通用遗物，包含技能、弹幕和其他构筑强化，不抽取即时补给。候选不足三项时展示剩余选项，全部满层不会卡住战斗。

战后先生成遗物候选，第一项优先本职业。存在可用补给时，第三项有 45% 概率替换为一种补给；不足三项则追加补给。精英战后三选一必含至少一项史诗或传说，章节首领的战后奖励也采用此保底；普通精英和强化精英规则一致。保底在补给替换后校验，补给不会挤掉唯一的高稀有选项。仍有未满层传说时可抽取传说；所有适用史诗与传说都满层时，用可重复领取的史诗军资补位。

| 奖励       | 效果             | 不出现的情况     |
| ---------- | ---------------- | ---------------- |
| 绯红药剂   | 立即恢复 40 生命 | 已满血           |
| 整编佣兵团 | 立即招募 50 人   | 兵力已到数值上限 |
| 精工锻造   | 武器等级 +1      | 武器已达 10 级   |

补给直接生效，不占遗物层数，也不占商店购买次数。一次奖励仍只取一项，需要在当下资源和长期构筑之间选择。

精英满池备用品仅用于高稀有遗物耗尽或候选不足，均为史诗消耗品，不加入普通奖励、升级、祭坛或商店：

| 名称     | 实际效果                              | 使用条件                                     |
| -------- | ------------------------------------- | -------------------------------------------- |
| 史诗军资 | 获得 120 金币，恢复 50 生命           | 高稀有池全满时的首选保底；也可填补极少的候选 |
| 不屈精粹 | 最大生命 +8（上限 500），恢复 50 生命 | 精英候选仍不足三项时补位                     |
| 王庭援军 | 获得 60 金币，招募 100 人             | 精英候选仍不足三项时补位                     |

因此，全部遗物和常规补给都已达到上限时，精英仍给出三项不重复的奖励；资源各自遵守生命与安全整数上限。角色升级仍只从常规遗物池选卡，最多获得 14 次升级选择。等级 L 升下一级需要 30 + 14×(L−1) + 6×max(0,L−5)² 经验，满级累计需 3404 XP。

## 传说强化

双翼符印、不灭圣约、月神之弦与群星之核属于传说稀有度，随机出现权重更低。其伤害、效果与层数上限没有因稀有度改名而增强；三职业终极强化最多 1 层，双翼符印最多 2 层。不要把更低的出现概率理解为每局必出的配方。

条目、价格与奖励数据取自当前游戏模块；具体伤害、命中与首领生命由内部数值文档维护。公开目录只列商品自身的描述，特殊遭遇在战斗现场揭示。
