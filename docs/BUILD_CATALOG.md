# 飞行弹幕构筑与渡鸦商店

v0.5 新增 7 项通用弹幕词条与禁术钥印，总计 33 项遗物：15 项通用、每职业 6 项。原有职业身份和构筑详见 [人物与流派](CHARACTERS.md)。本页按当前 `lib/game.ts` 数据和飞行弹体机制整理，不给出未经新版审计的胜率。

## 弹幕怎样命中

普通射击自动向前发射实际弹体，横移决定发射位置，弹体不追踪或锁定敌人。射偏后继续前飞，直到离开场地；穿透弹可以继续命中后方目标。主动职业技能保留其护盾或全场打击效果，与普通弹体分开结算。

主弹伤害仍由攻击强度与兵力倍率相乘得到。面板「理论主弹 DPS」只估算主弹、攻速与平均暴击收益；实际输出取决于命中率，还可能受到副弹、穿透、爆裂、低血增伤、回响、碎片、灼烧和技能影响。多枚弹体不代表必定全部命中同一个首领。

兵力倍率始终使用 `1 + log2(1 + 兵力 / 12)`。人数越多，火力越高；没有高兵力阶段的额外削减。实际兵力保留到安全整数上限，平方运算仍按真实人数平方后保护数值范围。

## 七项新增词条

以下表格由当前遗物数据生成，除另有说明外，百分比按层数线性累加。

| ID       | 名称     | 稀有度 | 最大层数 | 效果                                                |
| -------- | -------- | ------ | -------- | --------------------------------------------------- |
| split    | 双翼符印 | 稀有   | 2        | 每层增加左右一对斜向副弹，每枚造成主弹 50% 伤害。   |
| pierce   | 贯阵尖锥 | 稀有   | 3        | 每层多穿透 1 个目标，每次穿透后保留 75% 伤害。      |
| velocity | 疾风导环 | 普通   | 2        | 弹体飞行速度 +25%。                                 |
| blast    | 炼金火芯 | 稀有   | 3        | 命中时，对周围其他目标造成弹体伤害 30% 的范围伤害。 |
| heavy    | 铅铸重弹 | 普通   | 2        | 主弹伤害 +25%，攻击速度 −10%。                      |
| focus    | 聚能刻印 | 普通   | 2        | 弹体半径 +30%，伤害 +10%。                          |
| execute  | 终猎契印 | 稀有   | 2        | 对生命低于 30% 的目标，额外伤害 +20%。              |

- **散射**：每层增加一对副弹，最多额外 4 枚；加上主弹，常规齐射最多 5 枚。副弹以斜角前飞，不自动寻找目标。
- **穿透**：最多额外穿过 3 个目标；每次穿透后伤害乘 0.75，按经过目标的次序递减。穿透不是无视护甲。
- **重弹与聚能**：共同组成一个伤害加成项 `1 + 0.25×heavy层数 + 0.10×focus层数`；重弹另使攻速乘 `1 − 0.10×heavy层数`。两者不会各自独立相乘。
- **终猎契印**：只对当前生命比例低于 30% 的目标增加伤害，不是直接处决，也不是额外暴击判定。

### 五个搭配方向

| 方向     | 主要组合                                     | 操作与弱点                                                                         |
| -------- | -------------------------------------------- | ---------------------------------------------------------------------------------- |
| 穿透爆裂 | 贯阵尖锥 + 炼金火芯 + 疾风导环               | 尽量把前后目标放在弹道上，让多次命中覆盖附近敌人；空旷场地和孤立目标会降低范围收益 |
| 多重暴击 | 双翼符印 + 鹰隼之眼 + 追猎回响，可补致命瞄准 | 游侠以散射覆盖和暴击碎片处理多目标；碎片不会转弯追敌，不能按理论弹数承诺单体倍率   |
| 重弹收割 | 铅铸重弹 + 终猎契印 + 聚能刻印               | 以更大的主弹和单发伤害收尾；攻速下降会减少开火机会，仍需稳定瞄准                   |
| 骑士破阵 | 盾锋相映 + 誓言回响 + 贯阵尖锥，可补铅铸重弹 | 用护盾维持伤害，向前打穿阵列；护盾耗尽会同时削弱生存与输出                         |
| 法师纵火 | 法术回响 + 魔力奔涌 + 炼金火芯，可补疾风导环 | 回响和爆裂形成持续输出，弹速减少目标移动期间的落空；固定灼烧仍需直击成长支撑       |

这些是可形成协同的选择方向，不是预设职业套装、必出配方或通关保证。通用弹幕遗物不计入三层职业共鸣；选取它们时仍需给职业核心留出强化机会。

### 交易规则

`shopInventory(run)` 决定可见库存；`shopItemAvailability(run, id)` 返回可购状态和原因，供界面显示；`canBuyShopItem(run, id)` 与 `shopBuy(run, id)` 使用同一校验规则。

- 不在商店、商品不存在、金币不足或本店已购买时，不改变原始状态。
- 满血不能购买治疗；武器 10 级不能锻造；兵力到达安全整数上限不能招募。
- 遗物满层或职业不适用时不收费；随机遗物无候选时不收费。
- 最大生命提升来自定向购买橡木之心，同时按该遗物恢复生命；即使原先满血，也能正常获得上限提升。
- 治疗最多恢复至当前生命上限，招募最多至安全整数上限。已有但未满层的遗物可在后续商店继续购买。
- 购买成功后才保存本店购买记录，原始 Run 对象保持不变，便于页面和存档原子更新。

本轮保持 `Run.version = 3`。旧商品购买记录、新词条层数和定向商品记录照常保存；旧 v2/v3 档缺少 `squareGateSeen` 时补为 `false`，已存在但不是 boolean 的值会拒绝恢复。

## 禁术钥印与一次性试炼

| ID         | 名称     | 所属 | 稀有度 / 上限 | 效果                                                                          |
| ---------- | -------- | ---- | ------------- | ----------------------------------------------------------------------------- |
| square_key | 禁术钥印 | 通用 | 史诗 / 1      | 下一次精英关开启禁术试炼：先通过5道必经削减门，再争夺极窄平方门。本局限一次。 |

钥印不在常规随机奖励、商店或祭坛的池中。仅精英或章节首领战后的奖励阶段，在 `floor >= 4`（已完成至少四层）、未持有钥印且未开启试炼时，有 12% 概率用它替换第三候选；不足三项则追加，候选不重复。获取后地图会提示下一次精英的试炼。

普通精英不会固定出现平方门。携带钥印进入下一次精英时，`squareGateSeen` 立即变为 `true`，表示本局机会已开启；是否击败关底、是否成功经过平方门，都不会再次提供试炼或钥印。

试炼先连续出现五道全宽、必经的红色削减门，依次为减去当前兵力 18%、除以 1.30、减去 22%、除以 1.35、减去 25%。随后才出现极窄的 `x²` 门，旁边提供 `√x` 和加法门作为选择；平方通道实际约占场地宽度的 7.6%。承受前五道削减不保证最终能选中平方。

平方先把现有兵力平方，平方根先向下取整，随后统一添加职业和遗物招募，最后保护最少 1 人和安全整数上限。一般加减门仍按兵力缩放。

平方属于正向门，会触发骑士誓言回响补盾；平方根不触发正向补盾。两者都正常结算法师的过门招募。加减门标签和兵力显示采用万、亿、兆缩写，乘除门仍显示原倍率。

## 验证

新增 `tests/shop.test.mjs` 覆盖库存唯一性、职业过滤、每店限购、跨店满层、无效交易不扣款、空奖池、随机回退、治疗/招募/生命上限、弹幕词条参数与 v3 存档兼容。钥印测试覆盖奖励来源、稀有出现、第三槽和短池候选、持有或已开启后不再出现、旧存档默认值和非法字段拒绝；还确认全兵力范围保持原始火力公式。另已用实际函数核对平方/平方根标签、取整、招募顺序、正向补盾和大数上限。

飞行碰撞、散射、穿透、爆裂、碎片和首领战由战斗模块的机制测试验证；完整新版胜率与手感仍应以独立审计和试玩反馈为准。
