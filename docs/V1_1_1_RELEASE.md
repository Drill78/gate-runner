# 1.1.1 · 誓术觉醒与无垠军势

## 本次改动

- 骑士：原护盾保留；5秒伤害+25%。不灭圣约冷却8秒、盾额外+12，5秒增伤提高到40%。
- 游侠：全场箭雨4倍单次伤害，5秒攻速×2、暴击率+100个百分点；超出100%的部分1:1转为额外暴伤。月神之弦将箭雨增至6倍，并保留常驻15个百分点暴击与8秒冷却。
- 法师：兵力×1.05（向上取整），随后6枚追踪火球，每枚伤害为强化后单次火力的1.5倍，锁定最近敌军，目标死亡后重新锁定。群星之核为9枚火球、兵力×1.08、8秒冷却；灼烧符文仍可被火球点燃。
- 门：使用同一有效倍率来渲染与结算。双生印记会立即体现在场上乘法门上，不重复加成；加法门援军也显示实际数值。
- 事件：每次三项奇遇加保底路资。提高招募、锻造、生命井、宝库和贤者收益；新增免费薪火、职业传说传承，免费回礼治疗。事件各项数值和费用见数值册。
- 史册：历史记录支持收藏、取消收藏、只看珍藏。收藏保存于服务器，限定记录主人；公共排行不展示私人收藏状态。
- 兵力：取消约9007兆的旧安全整数限制，以尾数和指数保存约15位有效数字。平方、开方、倍率、比例损失、巨大加减门、法师增兵、存档、战绩显示与排序共同支持超过10^308的兵力。
- 无尽：层按章节首领计算，一层5关、三层15关。前15关起步平缓，以后每15关提高生命预算与攻击压力；敌人预算不跟随玩家兵力改变。后期曲线结合重铸、盟约和武器成长继续上升。

## 兼容与限制

保留v4存档、旧名字、称号、排行榜记录和八首音乐。新迁移0001增加收藏，0002增加兵力尾数与指数并转换旧排名；没有改写已应用的0000迁移。旧客户端的战绩请求仍可保存。

军团以约15位有效数字近似表示，极小的固定招募在天文数量级下不会改变有效位。指数边界为最大安全整数；普通数值字段1e300只是兼容投影。金币和其他计数没有随兵力一起改为科学计数存储。详见调试册的实际公式与上限。

验证：160项机制/接口测试、TypeScript、lint、静态与Worker生产构建通过。12次普通/困难回归、12次无尽150关对照、12次固定起点的15关平方窗口探针全部达到目标。窗口探针中，平方组的章节首领交战时间合计减少约45.5%；此计算扣除了固定出怪等待，完整结果见 [平衡审计](releases/v1.1.1-balance.json)。最终部署结果另见发布交接。自动驾驶样本只用于版本回归和对照，不等于真人通关概率；没有进行浏览器交互或真机试玩。
