# gate-runner · 灰烬之门 / Ashen Gates

Gate Runner × Roguelike，原创中世纪奇幻十二层远征。当前版本 **v0.5**。

**[立即试玩](https://gate-runner-seven.vercel.app)** · [GitHub 仓库](https://github.com/Drill78/gate-runner)

- 手机竖屏整屏战场、透明边缘信息、角色抽屉菜单；主角位于画面下部，兵力大字与获得提示跟随人物，技能在右侧。
- 远处目标提前 1.25 秒可见，放大敌人体积；击杀获得金币和经验，局内升级。
- 向前飞行的真实弹幕，靠横移瞄准；打空继续飞过敌人，穿透、多重散射和爆裂都有实际碰撞效果。
- 不同宽度的两门或三门选择，第二层起加减值按兵力放大；精英关提供开方门；平方仅由稀有「禁术钥印」开启，需先通过5道必经红门，再争夺极窄通道。
- 关底精英与章节 Boss 均有横向大血条，显示名称、精确生命和战斗状态。
- 三职业完整立绘、五种首领独立立绘、33 项可叠加遗物；商店共 17 种商品，每职业可见 15 种，包括可定向购买的弹幕遗物。
- 每幕 8 / 10 / 12 波，打宝箱升武器；首领使用散斧、正面举盾、交错星弹、交叉火弹和可打断吟唱。
- 首领停留在画面上方约三成处，章节 Boss 生命在 v0.4 基础上翻倍，并保留逐步增强的全屏压力。
- 首领带墨迹、速度线和立绘定格突入；演出暂停战斗，可点击、空格或回车跳过。三职业拥有不同弹体与技能特效。
- 首次打开自动显示四页图文教程，暂停菜单可重看；分支地图、战后三选一、营火、商店、祭坛事件、本地存档。

## 运行

需要 Node.js 24。

```sh
npm ci
npm run dev
npm run build
npm start
```

默认生产构建输出 `dist/`，可直接部署 Vercel 或 Netlify，无服务端和环境变量需求。A/D 或左右方向键按住移动，空格释放技能，P/Esc 暂停；手机点击或拖动场地，右侧按钮释放职业技能，左上角「角色」查看详情并暂停战斗。

## 代码结构

- `lib/game.ts`：职业、遗物、地图、房间、经济、经验等级与存档迁移。
- `lib/combat.ts`：连续移动、敌人波次、门、弹幕、吟唱、章节压力与战斗。
- `lib/bosses.ts`：五种首领的立绘、称号、台词与应对提示。
- `lib/renderer.ts`、`lib/view.ts`：固定比例俯视 Canvas 和共用视野投影。
- `app/page.tsx`、`components/game-panels.tsx`：完整远征流程与界面。
- `scripts/balance-sim.mjs`：遵守移动速度的自动模拟器。

本版的 3D 风格立绘是 2D 图像，尚无真正 3D 模型或骨骼动画。存档只在当前浏览器；v0.5 沿用格式 v3，无需新增迁移。v0.2 的格式 v2 存档仍可自动迁移，保留进度，经验从零起步；不兼容 v0.1 远征。所有美术和游戏资源从本站加载，没有外部字体/CDN 依赖。
