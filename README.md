# gate-runner · 灰烬之门 / Ashen Gates

Gate Runner × Roguelike，原创中世纪奇幻远征：三幕各五关，以及六轮长夜、登神长阶与祝福尾声。当前版本 **1.2.1 · 登神远征**。

**[立即试玩](https://gate-runner-seven.vercel.app)** · [GitHub 仓库](https://github.com/Drill78/gate-runner)

## 运行

需要 Node.js 24。

```sh
npm ci
npm run dev
npm run build
npm start
```

默认生产构建输出静态前端 `dist/`。公共史册由 Sites Worker/D1 提供，Vercel 将 `/api/chronicle/` 代理到现有后端；`npm run build:sites` 构建同版 Worker 与迁移。A/D 或左右方向键按住移动，空格释放技能，P/Esc 暂停；手机点击或拖动场地，右侧按钮释放职业技能，左上角「角色」查看详情并暂停战斗。暂停菜单可开启「双击人物释放技能」，默认关闭，偏好保存在当前浏览器。

## 代码结构

- `lib/game.ts`：职业、遗物、地图、房间、经济、经验等级与存档迁移。
- `lib/combat.ts`：连续移动、敌人波次、门、弹幕、吟唱、章节压力与战斗。
- `lib/bosses.ts`：五种精英、八种章节首领／形态的立绘、称号、台词与应对提示。
- `lib/collection.ts`、`components/collection-panel.tsx`：永久图鉴、击败计数、职业通关与成就。
- `components/gate-entrance.tsx`：圣门开启与职业选择入口。
- `lib/renderer.ts`、`lib/view.ts`：固定比例俯视 Canvas 和共用视野投影。
- `app/page.tsx`、`components/game-panels.tsx`：完整远征流程与界面。
- `scripts/balance-sim.mjs`：遵守移动速度的自动模拟器。

本版的 3D 风格立绘是 2D 图像，尚无真正 3D 模型或骨骼动画。远征存档使用格式 v4，收藏单独保存，均仅存在当前浏览器。格式 v2/v3 旧档迁移时保留资源、经验与已选强化，回到对应幕起点重新选路，并保留待领取奖励；没有经验字段的 v2 档从零经验起步。不兼容 v0.1 远征。所有美术和游戏资源从本站加载，没有外部字体/CDN 依赖。
